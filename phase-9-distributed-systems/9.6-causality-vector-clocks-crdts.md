## Concept

In strict CP consensus systems (like Raft), writes cannot be accepted if a node is partitioned from the majority.

In **AP (Available / Partition-Tolerant)** systems, collaborative applications (like Google Docs, Figma, Apple Notes), and multi-region databases (DynamoDB, Riak), nodes **must continue accepting writes even while completely disconnected**.

When partitioned nodes re-establish network communication, how do they merge conflicting edits without losing data?

1. **Vector Clocks**: Track exact causality and detect true concurrency ($A \parallel B$).
2. **Conflict-Free Replicated Data Types (CRDTs)**: Mathematical data structures that **guarantee deterministic convergence** without centralized coordination.

```
                  Concurrent Writes on Two Disconnected Replicas
   Node A: "Title: Rust for Systems"   [ V_A: {A:1, B:0} ]
                      │
   Network Partition! ├──────────────────────────────────────────┐
                      ▼                                          ▼
   Node A: "Title: Rust for Masters"   Node B: "Title: High-Perf Rust"
   [ V_A: {A:2, B:0} ]                 [ V_B: {A:0, B:1} ]
                      │                                          │
                      └───────────────────┬──────────────────────┘
                                          │ Network Reconnects!
                                          ▼
                    Vector Clock Comparison: {A:2, B:0} || {A:0, B:1}
                    CONCURRENCY DETECTED! Merged via CRDT Rules!
```

---

### 1. Vector Clock Comparison Mathematics

Let $V_A$ and $V_B$ be vector clocks of size $N$:

1. $V_A \le V_B \iff \forall k \in [1..N], V_A[k] \le V_B[k]$
2. $V_A < V_B \iff (V_A \le V_B) \land (V_A \ne V_B)$ $\implies \mathbf{A \text{ happened before } B}$
3. If neither $V_A \le V_B$ nor $V_B \le V_A$, then $\mathbf{A \parallel B \text{ (Concurrent Conflict)}}$.

---

### 2. State-Based CRDTs (CvRDT) & The Semilattice

A data type is a state-based CRDT if its state space forms a **Bounded Join-Semilattice** with a merge function $\sqcup$ possessing three mathematical properties:

1. **Commutative**: $A \sqcup B = B \sqcup A$ (Message delivery order does not matter).
2. **Associative**: $(A \sqcup B) \sqcup C = A \sqcup (B \sqcup C)$ (Message batching does not matter).
3. **Idempotent**: $A \sqcup A = A$ (Duplicate messages do not alter state).

#### Common CRDT Types:
- **G-Counter (Grow-Only Counter)**: Each node has its own slot. Value is the sum of all slots. Merge takes $\max(\text{slot}_A, \text{slot}_B)$.
- **PN-Counter (Positive-Negative Counter)**: Two G-Counters (one for increments, one for decrements).
- **LWW-Element-Set (Last-Write-Wins Element Set)**: Adds and removes elements with timestamps; tie-breaker deterministically picks winner.
- **OR-Set (Observed-Remove Set)**: Uses unique UUID tags for each added element. Removing an element deletes only the tags observed at that moment.

---

## Why It Matters in Systems Programming

1. **Local-First & Offline-First Software**: Desktop and mobile applications (like Obsidian or Figma) edit local state instantly at $0\text{ms}$ latency and sync seamlessly when Wi-Fi reconnects.
2. **Multi-Master Global Databases**: Allows active-active writes in London, Tokyo, and New York simultaneously with zero inter-continental blocking locks.
3. **Mathematically Proven Convergence**: Eliminates ad-hoc conflict resolution logic that causes data corruption.

## Complete, Compilable Code Example

Below is a complete, self-contained implementation of **Vector Clocks**, a **G-Counter**, and a **PN-Counter CRDT** in pure Rust:

```rust
use std::cmp::max;
use std::collections::BTreeMap;

// ============================================================================
// 1. Vector Clock Implementation
// ============================================================================

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct VectorClock {
    pub clocks: BTreeMap<u32, u64>, // NodeID -> Counter
}

#[derive(Debug, PartialEq, Eq)]
pub enum ClockOrdering {
    Equal,
    Before,     // self < other (self happened before other)
    After,      // self > other (self happened after other)
    Concurrent, // self || other (conflict!)
}

impl VectorClock {
    pub fn new() -> Self {
        Self {
            clocks: BTreeMap::new(),
        }
    }

    pub fn increment(&mut self, node_id: u32) {
        *self.clocks.entry(node_id).or_insert(0) += 1;
    }

    pub fn merge(&mut self, other: &VectorClock) {
        for (&node_id, &remote_cnt) in &other.clocks {
            let local_cnt = self.clocks.entry(node_id).or_insert(0);
            *local_cnt = max(*local_cnt, remote_cnt);
        }
    }

    /// Compare causality between two vector clocks
    pub fn compare(&self, other: &VectorClock) -> ClockOrdering {
        let mut self_has_greater = false;
        let mut other_has_greater = false;

        let all_keys: std::collections::BTreeSet<u32> = self
            .clocks
            .keys()
            .chain(other.clocks.keys())
            .copied()
            .collect();

        for key in all_keys {
            let v_self = self.clocks.get(&key).copied().unwrap_or(0);
            let v_other = other.clocks.get(&key).copied().unwrap_or(0);

            if v_self > v_other {
                self_has_greater = true;
            } else if v_other > v_self {
                other_has_greater = true;
            }
        }

        match (self_has_greater, other_has_greater) {
            (false, false) => ClockOrdering::Equal,
            (true, false) => ClockOrdering::After,
            (false, true) => ClockOrdering::Before,
            (true, true) => ClockOrdering::Concurrent,
        }
    }
}

// ============================================================================
// 2. Positive-Negative Counter CRDT (PN-Counter)
// ============================================================================

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PnCounter {
    pub node_id: u32,
    pub p_counters: BTreeMap<u32, u64>, // Increments
    pub n_counters: BTreeMap<u32, u64>, // Decrements
}

impl PnCounter {
    pub fn new(node_id: u32) -> Self {
        Self {
            node_id,
            p_counters: BTreeMap::new(),
            n_counters: BTreeMap::new(),
        }
    }

    pub fn increment(&mut self, amount: u64) {
        *self.p_counters.entry(self.node_id).or_insert(0) += amount;
    }

    pub fn decrement(&mut self, amount: u64) {
        *self.n_counters.entry(self.node_id).or_insert(0) += amount;
    }

    pub fn value(&self) -> i64 {
        let p_sum: u64 = self.p_counters.values().sum();
        let n_sum: u64 = self.n_counters.values().sum();
        p_sum as i64 - n_sum as i64
    }

    /// Pure CRDT Join-Semilattice Merge (Commutative, Associative, Idempotent)
    pub fn merge(&mut self, other: &PnCounter) {
        // Merge Positive Counters with max()
        for (&id, &remote_p) in &other.p_counters {
            let local_p = self.p_counters.entry(id).or_insert(0);
            *local_p = max(*local_p, remote_p);
        }

        // Merge Negative Counters with max()
        for (&id, &remote_n) in &other.n_counters {
            let local_n = self.n_counters.entry(id).or_insert(0);
            *local_n = max(*local_n, remote_n);
        }
    }
}

// ============================================================================
// 3. Verification & Execution
// ============================================================================

fn main() {
    println!("=== 1. Testing Vector Clock Causality Comparison ===");
    let mut vc_a = VectorClock::new();
    let mut vc_b = VectorClock::new();

    vc_a.increment(1); // A: {1: 1}
    vc_b.merge(&vc_a); // B: {1: 1}
    vc_b.increment(2); // B: {1: 1, 2: 1}

    println!("VC A: {:?}, VC B: {:?}", vc_a.clocks, vc_b.clocks);
    println!("Comparison (A vs B): {:?}", vc_a.compare(&vc_b));
    assert_eq!(vc_a.compare(&vc_b), ClockOrdering::Before);

    // Simulate concurrent partition writes
    vc_a.increment(1); // A: {1: 2} (Did not see B's event)
    println!("\nAfter concurrent writes (Partition):");
    println!("VC A: {:?}, VC B: {:?}", vc_a.clocks, vc_b.clocks);
    println!("Comparison (A vs B): {:?}", vc_a.compare(&vc_b));
    assert_eq!(vc_a.compare(&vc_b), ClockOrdering::Concurrent);
    println!("✅ Correctly detected concurrent conflict (A || B)!\n");

    println!("=== 2. Testing PN-Counter CRDT Under Disconnected Writes ===");
    let mut replica_tokyo = PnCounter::new(1);
    let mut replica_london = PnCounter::new(2);

    println!("Tokyo increments by 50 (+50)");
    replica_tokyo.increment(50);

    println!("London decrements by 10 (-10) while disconnected!");
    replica_london.decrement(10);

    println!("Tokyo local value:  {}", replica_tokyo.value());
    println!("London local value: {}", replica_london.value());

    println!("\nReconnecting network and merging CRDT replicas...");
    replica_tokyo.merge(&replica_london);
    replica_london.merge(&replica_tokyo);

    println!("Tokyo Final Merged Value:  {}", replica_tokyo.value());
    println!("London Final Merged Value: {}", replica_london.value());

    assert_eq!(replica_tokyo.value(), 40);
    assert_eq!(replica_london.value(), 40);
    println!("✅ Replicas converged to exact balance (50 - 10 = 40) automatically!");
}
```

## Common Pitfalls & Compiler Errors

### 1. Decrementing a G-Counter
A Grow-Only Counter (G-Counter) relies on monotonic increments so `max(local, remote)` works. Decrementing a slot breaks monotonicity, causing merged values to discard decrements. Always use a **PN-Counter** with separate positive and negative counters.

### 2. State-Based vs Operation-Based CRDTs
State-based CRDTs (CvRDT) send full state snapshots, which grow with the number of nodes. Operation-based CRDTs (CmRDT) send smaller delta operations, but require reliable causal broadcast middleware.

## Complete Solutions to Exercises

### Solution 1: LWW-Register CRDT

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LwwRegister<T: Clone> {
    pub value: T,
    pub timestamp: u64,
    pub node_id: u32,
}

impl<T: Clone> LwwRegister<T> {
    pub fn merge(&mut self, other: &Self) {
        if other.timestamp > self.timestamp 
            || (other.timestamp == self.timestamp && other.node_id > self.node_id) 
        {
            self.value = other.value.clone();
            self.timestamp = other.timestamp;
            self.node_id = other.node_id;
        }
    }
}
```
