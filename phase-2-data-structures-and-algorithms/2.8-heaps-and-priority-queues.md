## Concept

A **Priority Queue** is an Abstract Data Type (ADT) where each element has a priority. Unlike a standard FIFO queue (where elements leave in arrival order), a priority queue always serves the element with the **highest priority first**.

The most efficient data structure for implementing a priority queue is a **Binary Heap**.

---

### 1. The Complete Binary Tree as a Flat Array

A **Complete Binary Tree** is a binary tree where every level is completely filled, except possibly the last level, which is filled from left to right.

Because of this rigid shape, a binary heap requires **no pointers or heap nodes**. Instead, it is packed contiguously inside a single `Vec<T>`:

```
Tree Representation:
                      [ 90 (0) ]
                     /          \
             [ 70 (1) ]        [ 80 (2) ]
             /        \        /        \
         [ 40 (3) ] [ 30 (4) ][ 60 (5) ][ 20 (6) ]

Array Representation:
 Index:    0    1    2    3    4    5    6
 Value:  [ 90,  70,  80,  40,  30,  60,  20 ]
```

#### Index Arithmetic Formulas (0-Indexed)
For any element at index `i`:
- **Parent**: `(i - 1) / 2` (valid when `i > 0`)
- **Left Child**: `2 * i + 1`
- **Right Child**: `2 * i + 2`

---

### 2. The Heap Invariants

- **Max-Heap Invariant**: For every node $i > 0$, `data[parent(i)] >= data[i]`. The **maximum element is always at the root (`index 0`)**.
- **Min-Heap Invariant**: For every node $i > 0$, `data[parent(i)] <= data[i]`. The **minimum element is always at the root (`index 0`)**.

> [!NOTE]
> A heap is **partially ordered**, not fully sorted. The root is guaranteed to be the extreme value, but sibling nodes have no defined relationship.

---

### 3. Core Heap Operations

#### A. Insertion (`push`) — $O(\log N)$
1. Append the new item to the end of the array.
2. **Sift-Up (Bubble-Up)**: Repeatedly swap the element with its parent while it violates the heap property.

```
Pushing 85 into [ 90, 70, 80, 40, 30, 60, 20 ]:
1. Append: [ 90, 70, 80, 40, 30, 60, 20, 85 (idx 7) ]
2. Parent of idx 7 is idx (7-1)/2 = 3 (val 40).
3. 85 > 40 -> Swap: [ 90, 70, 80, 85, 30, 60, 20, 40 ]
4. Parent of idx 3 is idx (3-1)/2 = 1 (val 70).
5. 85 > 70 -> Swap: [ 90, 85, 80, 70, 30, 60, 20, 40 ]
6. Parent of idx 1 is idx 0 (val 90). 85 < 90 -> Stop!
```

#### B. Extraction (`pop`) — $O(\log N)$
1. Swap the root element (`index 0`) with the last element.
2. Remove and return the last element.
3. **Sift-Down (Bubble-Down)**: Compare the new root with its children, swap with the larger child (in a max-heap), and repeat until the heap property is restored.

#### C. In-Place Heapify — $O(N)$
Converting an unsorted array into a valid heap can be done in $O(N)$ linear time by calling `sift_down` starting from the last non-leaf parent (`len / 2 - 1`) down to index `0`.

---

## Why it matters

- **OS Task Schedulers**: Operating systems use priority queues to schedule CPU time, ensuring real-time interrupt handlers execute ahead of background worker threads.
- **Dijkstra's Shortest Path Algorithm**: Graph pathfinding relies on a min-priority queue to explore the closest unvisited nodes first (covered in Lesson 2.12).
- **Zero-Allocation Tree**: Packing a tree into a flat array eliminates pointer-chasing and maximizes CPU L1/L2 data cache prefetching.

## Analogy

Think of an **Emergency Room Triage Desk**:
- Patients do not see doctors in the order they walked through the door (FIFO).
- Instead, each patient is assigned an urgency score (priority).
- A cardiac arrest patient (priority 100) immediately jumps ahead of a minor sprain (priority 10).

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
#[derive(Debug, Clone)]
pub struct MaxHeap<T> {
    data: Vec<T>,
}

impl<T: Ord> MaxHeap<T> {
    pub fn new() -> Self {
        MaxHeap { data: Vec::new() }
    }

    pub fn with_capacity(capacity: usize) -> Self {
        MaxHeap {
            data: Vec::with_capacity(capacity),
        }
    }

    pub fn len(&self) -> usize {
        self.data.len()
    }

    pub fn is_empty(&self) -> bool {
        self.data.is_empty()
    }

    pub fn peek(&self) -> Option<&T> {
        self.data.first()
    }

    // Insert element in O(log N)
    pub fn push(&mut self, value: T) {
        self.data.push(value);
        let last_idx = self.data.len() - 1;
        self.sift_up(last_idx);
    }

    // Remove and return maximum element in O(log N)
    pub fn pop(&mut self) -> Option<T> {
        if self.data.is_empty() {
            return None;
        }

        let last_idx = self.data.len() - 1;
        self.data.swap(0, last_idx);
        let max_val = self.data.pop();

        if !self.data.is_empty() {
            self.sift_down(0);
        }

        max_val
    }

    // Restore heap invariant moving up
    fn sift_up(&mut self, mut idx: usize) {
        while idx > 0 {
            let parent_idx = (idx - 1) / 2;
            if self.data[idx] > self.data[parent_idx] {
                self.data.swap(idx, parent_idx);
                idx = parent_idx;
            } else {
                break;
            }
        }
    }

    // Restore heap invariant moving down
    fn sift_down(&mut self, mut idx: usize) {
        let len = self.data.len();
        loop {
            let left_child = 2 * idx + 1;
            let right_child = 2 * idx + 2;
            let mut largest = idx;

            if left_child < len && self.data[left_child] > self.data[largest] {
                largest = left_child;
            }

            if right_child < len && self.data[right_child] > self.data[largest] {
                largest = right_child;
            }

            if largest != idx {
                self.data.swap(idx, largest);
                idx = largest;
            } else {
                break;
            }
        }
    }

    // Build heap from arbitrary Vec in linear O(N) time
    pub fn from_vec(mut items: Vec<T>) -> Self {
        let len = items.len();
        if len > 1 {
            let last_parent = (len / 2) - 1;
            let mut heap = MaxHeap { data: items };
            for i in (0..=last_parent).rev() {
                heap.sift_down(i);
            }
            heap
        } else {
            MaxHeap { data: items }
        }
    }
}

fn main() {
    let mut task_queue = MaxHeap::new();

    // Insert server tasks with priority
    task_queue.push(40);
    task_queue.push(90);
    task_queue.push(10);
    task_queue.push(80);
    task_queue.push(70);

    println!("Highest priority task: {:?}", task_queue.peek()); // Some(90)

    // Drain tasks in descending order of priority
    print!("Processing tasks: ");
    while let Some(task) = task_queue.pop() {
        print!("{} ", task);
    }
    println!();
    // Output: 90 80 70 40 10

    // O(N) linear heap construction
    let unsorted = vec![3, 1, 4, 1, 5, 9, 2, 6];
    let mut heap = MaxHeap::from_vec(unsorted);
    println!("Max after O(N) heapify: {:?}", heap.pop()); // Some(9)
}
```

## Common Mistakes

### 1. Unsigned Underflow on Parent Calculation at Root
Computing `parent = (0 - 1) / 2` with `usize` will cause an underflow panic in debug mode (`usize::MAX / 2`).
```rust
// ❌ FAILS at idx == 0: attempts 0usize - 1
let parent = (idx - 1) / 2;

// ✅ CORRECT: Guard loop condition with idx > 0
while idx > 0 {
    let parent = (idx - 1) / 2;
    ...
}
```

---

### 2. Out-of-Bounds Child Lookups
Accessing `self.data[2 * idx + 1]` without first ensuring `2 * idx + 1 < self.data.len()`. This causes an out-of-bounds index panic when reaching leaf nodes.

---

### 3. Assuming Sibling Order
Assuming `data[1]` (left child) is always larger than `data[2]` (right child). A heap only establishes parent-child relationships, never sibling relationships.

## Solutions

### Solution to Exercise 1
```rust
#[derive(Debug)]
pub struct MinHeap<T> {
    data: Vec<T>,
}

impl<T: Ord> MinHeap<T> {
    pub fn new() -> Self {
        MinHeap { data: Vec::new() }
    }

    pub fn push(&mut self, val: T) {
        self.data.push(val);
        let mut idx = self.data.len() - 1;
        while idx > 0 {
            let parent = (idx - 1) / 2;
            if self.data[idx] < self.data[parent] {
                self.data.swap(idx, parent);
                idx = parent;
            } else {
                break;
            }
        }
    }

    pub fn pop(&mut self) -> Option<T> {
        if self.data.is_empty() {
            return None;
        }
        let last = self.data.len() - 1;
        self.data.swap(0, last);
        let min = self.data.pop();
        if !self.data.is_empty() {
            let mut idx = 0;
            let len = self.data.len();
            loop {
                let left = 2 * idx + 1;
                let right = 2 * idx + 2;
                let mut smallest = idx;
                if left < len && self.data[left] < self.data[smallest] {
                    smallest = left;
                }
                if right < len && self.data[right] < self.data[smallest] {
                    smallest = right;
                }
                if smallest != idx {
                    self.data.swap(idx, smallest);
                    idx = smallest;
                } else {
                    break;
                }
            }
        }
        min
    }
}
```

### Solution to Exercise 2
```rust
pub fn heapsort<T: Ord>(slice: &mut [T]) {
    let len = slice.len();
    if len <= 1 {
        return;
    }

    // Step 1: Heapify in-place (Max-Heap)
    for i in (0..=(len / 2 - 1)).rev() {
        sift_down_range(slice, i, len);
    }

    // Step 2: Extract max and shrink heap window
    for end in (1..len).rev() {
        slice.swap(0, end);
        sift_down_range(slice, 0, end);
    }
}

fn sift_down_range<T: Ord>(slice: &mut [T], mut idx: usize, len: usize) {
    loop {
        let left = 2 * idx + 1;
        let right = 2 * idx + 2;
        let mut largest = idx;

        if left < len && slice[left] > slice[largest] {
            largest = left;
        }
        if right < len && slice[right] > slice[largest] {
            largest = right;
        }

        if largest != idx {
            slice.swap(idx, largest);
            idx = largest;
        } else {
            break;
        }
    }
}
```

### Solution to Exercise 3
```rust
use std::cmp::Reverse;
use std::collections::BinaryHeap;

pub fn find_top_k(stream: &[u64], k: usize) -> Vec<u64> {
    if k == 0 {
        return Vec::new();
    }

    // Use standard library Min-Heap via Reverse
    let mut min_heap = BinaryHeap::with_capacity(k);

    for &item in stream {
        if min_heap.len() < k {
            min_heap.push(Reverse(item));
        } else if let Some(&Reverse(smallest)) = min_heap.peek() {
            if item > smallest {
                min_heap.pop();
                min_heap.push(Reverse(item));
            }
        }
    }

    min_heap.into_iter().map(|Reverse(v)| v).collect()
}

fn main() {
    let mut data = [55, 12, 89, 42, 99, 1, 74, 30];
    heapsort(&mut data);
    println!("Heapsorted: {:?}", data);
    assert_eq!(data, [1, 12, 30, 42, 55, 74, 89, 99]);

    let top3 = find_top_k(&data, 3);
    println!("Top 3 items: {:?}", top3);
}
```
