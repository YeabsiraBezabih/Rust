## Concept

Graph traversal is the process of visiting every reachable vertex and edge in a graph. Because graphs can contain loops (**cycles**), any traversal algorithm must track which nodes have already been visited to prevent infinite loops.

```
       (A)
      /   \
    (B)   (C)
    / \     \
  (D) (E)──►(F)
```

---

### 1. Breadth-First Search (BFS) — Level-by-Level Exploration

BFS explores neighbors in concentric layers, visiting all nodes at distance 1 before moving to distance 2:
- **Data Structure**: Uses a **FIFO Queue** (`VecDeque<usize>`).
- **Core Property**: Guaranteed to find the **shortest path in unweighted graphs** (fewest edge hops).
- **Time Complexity**: **$O(V + E)$**.
- **Space Complexity**: **$O(V)$** (to store the visited set and queue).

```
BFS Order starting from A:
Layer 0: A
Layer 1: B, C
Layer 2: D, E, F
```

---

### 2. Depth-First Search (DFS) — Deep Branch Exploration

DFS dives down a single branch as deeply as possible until hitting a dead end or already-visited node, then backtracks:
- **Data Structure**: Uses a **LIFO Stack** (via recursion or an explicit `Vec<usize>`).
- **Core Property**: Excellent for topological sorting, cycle detection, maze solving, and component analysis.
- **Time Complexity**: **$O(V + E)$**.
- **Space Complexity**: **$O(V)$** (recursion depth in worst case).

```
DFS Order starting from A:
A ──► B ──► D (dead end, backtrack to B)
  ──► E ──► F (dead end, backtrack to E ──► B ──► A)
  ──► C (already visited F, finish)
```

---

### 3. Cycle Detection and Three-Coloring (DFS)

To detect cycles in a directed graph, nodes are marked with three states:
1. **White (Unvisited)**: Node has not been encountered.
2. **Gray (Visiting)**: Node is in the active recursion call stack.
3. **Black (Visited)**: Node and all descendants are fully explored.

> [!IMPORTANT]
> If a DFS traversal encounters a **Gray** node, a **cycle exists** (the graph contains a backward dependency loop).

---

## Why it matters

- **Dependency Resolution (Topological Sort)**: Cargo resolves crate build order by running DFS to ensure dependencies are compiled before downstream crates.
- **Peer-to-Peer Gossiping**: Blockchain and P2P protocols (e.g., BitTorrent, Ethereum) use BFS to flood-broadcast transactions to nearest network peers.
- **Garbage Collection**: Tracing GC runs BFS/DFS from "roots" (stack pointers, globals) to mark live objects on the heap.

---

## Analogy

- **BFS**: Ripples expanding outward when a stone is dropped in water. Every point at radius $R$ is touched before anything at radius $R + 1$.
- **DFS**: Exploring a labyrinth with a ball of string. You walk down one corridor until hitting a wall, rewind the string to the previous fork, and try the next passage.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::collections::{HashMap, HashSet, VecDeque};

#[derive(Debug, Clone)]
pub struct Graph<N> {
    nodes: Vec<N>,
    node_lookup: HashMap<N, usize>,
    adjacency: Vec<Vec<usize>>,
    is_directed: bool,
}

impl<N: Clone + Eq + std::hash::Hash + std::fmt::Debug> Graph<N> {
    pub fn new(is_directed: bool) -> Self {
        Graph {
            nodes: Vec::new(),
            node_lookup: HashMap::new(),
            adjacency: Vec::new(),
            is_directed,
        }
    }

    pub fn add_node(&mut self, node: N) -> usize {
        if let Some(&index) = self.node_lookup.get(&node) {
            return index;
        }
        let index = self.nodes.len();
        self.node_lookup.insert(node.clone(), index);
        self.nodes.push(node);
        self.adjacency.push(Vec::new());
        index
    }

    pub fn add_edge(&mut self, from: N, to: N) {
        let u = self.add_node(from);
        let v = self.add_node(to);

        self.adjacency[u].push(v);
        if !self.is_directed {
            self.adjacency[v].push(u);
        }
    }

    // 1. Breadth-First Search (BFS)
    pub fn bfs(&self, start: &N) -> Vec<N> {
        let mut visited = vec![false; self.nodes.len()];
        let mut queue = VecDeque::new();
        let mut order = Vec::new();

        if let Some(&start_idx) = self.node_lookup.get(start) {
            visited[start_idx] = true;
            queue.push_back(start_idx);

            while let Some(current) = queue.pop_front() {
                order.push(self.nodes[current].clone());

                for &neighbor in &self.adjacency[current] {
                    if !visited[neighbor] {
                        visited[neighbor] = true; // Mark visited upon ENQUEUE
                        queue.push_back(neighbor);
                    }
                }
            }
        }

        order
    }

    // 2. Depth-First Search (DFS)
    pub fn dfs(&self, start: &N) -> Vec<N> {
        let mut visited = vec![false; self.nodes.len()];
        let mut order = Vec::new();

        if let Some(&start_idx) = self.node_lookup.get(start) {
            self.dfs_recursive(start_idx, &mut visited, &mut order);
        }

        order
    }

    fn dfs_recursive(&self, current: usize, visited: &mut [bool], order: &mut Vec<N>) {
        visited[current] = true;
        order.push(self.nodes[current].clone());

        for &neighbor in &self.adjacency[current] {
            if !visited[neighbor] {
                self.dfs_recursive(neighbor, visited, order);
            }
        }
    }

    // 3. Cycle Detection in Directed Graph using 3-Coloring
    pub fn has_cycle(&self) -> bool {
        assert!(self.is_directed, "has_cycle 3-coloring is for directed graphs");
        #[derive(Clone, Copy, PartialEq)]
        enum State {
            White, // Unvisited
            Gray,  // Visiting (on current recursion stack)
            Black, // Visited
        }

        let mut states = vec![State::White; self.nodes.len()];

        for i in 0..self.nodes.len() {
            if states[i] == State::White && self.detect_cycle_dfs(i, &mut states) {
                return true;
            }
        }
        false
    }

    fn detect_cycle_dfs(&self, u: usize, states: &mut [State]) -> bool {
        states[u] = State::Gray;

        for &v in &self.adjacency[u] {
            match states[v] {
                State::Gray => return true, // Found back-edge to ancestor -> Cycle!
                State::White => {
                    if self.detect_cycle_dfs(v, states) {
                        return true;
                    }
                }
                State::Black => {}
            }
        }

        states[u] = State::Black;
        false
    }
}

fn main() {
    let mut network = Graph::new(true);

    network.add_edge("Router_A", "Switch_B");
    network.add_edge("Router_A", "Switch_C");
    network.add_edge("Switch_B", "Host_D");
    network.add_edge("Switch_B", "Host_E");
    network.add_edge("Switch_C", "Host_F");
    network.add_edge("Host_E", "Host_F");

    println!("BFS Order from Router_A: {:?}", network.bfs(&"Router_A"));
    println!("DFS Order from Router_A: {:?}", network.dfs(&"Router_A"));
    println!("Has dependency cycle?   : {}", network.has_cycle());

    // Introduce a cycle
    network.add_edge("Host_F", "Router_A");
    println!("Has cycle after loop?   : {}", network.has_cycle()); // true
}
```

## Common Mistakes

### 1. Marking Nodes as Visited *After Dequeueing* in BFS
If you mark a node as visited when it is *popped* from the queue rather than when *pushed*, the same neighbor can be enqueued hundreds of times by parallel paths, causing exponential memory growth.

```rust
// ❌ FAILS: Multiple duplicate queue entries
while let Some(curr) = queue.pop_front() {
    visited[curr] = true;
    for &next in &self.adjacency[curr] {
        if !visited[next] { queue.push_back(next); }
    }
}

// ✅ CORRECT: Mark visited immediately upon enqueueing
if !visited[next] {
    visited[next] = true;
    queue.push_back(next);
}
```

---

### 2. Missing Disconnected Components
Running BFS/DFS only from `start_idx` will miss nodes in disconnected subgraphs. To traverse an entire forest of disconnected components, wrap the traversal in an outer loop over all vertex indices `0..V`.

---

### 3. Stack Overflow on Massive Linear Graphs
A recursive DFS on a linear chain of $1,000,000$ vertices will exhaust the OS stack frame limit ($2\text{MB}-8\text{MB}$) and panic. Use an explicit heap-allocated `Vec<usize>` stack for deep traversals.

## Solutions

### Solution to Exercise 1
```rust
impl<N: Clone + Eq + std::hash::Hash + std::fmt::Debug> Graph<N> {
    pub fn shortest_path(&self, from: &N, to: &N) -> Option<Vec<N>> {
        let &start_idx = self.node_lookup.get(from)?;
        let &end_idx = self.node_lookup.get(to)?;

        let mut visited = vec![false; self.nodes.len()];
        let mut parent = vec![None; self.nodes.len()];
        let mut queue = VecDeque::new();

        visited[start_idx] = true;
        queue.push_back(start_idx);

        let mut found = false;
        while let Some(curr) = queue.pop_front() {
            if curr == end_idx {
                found = true;
                break;
            }

            for &neighbor in &self.adjacency[curr] {
                if !visited[neighbor] {
                    visited[neighbor] = true;
                    parent[neighbor] = Some(curr);
                    queue.push_back(neighbor);
                }
            }
        }

        if !found {
            return None;
        }

        // Backtrack path
        let mut path = Vec::new();
        let mut curr = Some(end_idx);
        while let Some(idx) = curr {
            path.push(self.nodes[idx].clone());
            curr = parent[idx];
        }
        path.reverse();
        Some(path)
    }
}
```

### Solution to Exercise 2
```rust
impl<N: Clone + Eq + std::hash::Hash + std::fmt::Debug> Graph<N> {
    pub fn topological_sort(&self) -> Option<Vec<N>> {
        if self.has_cycle() {
            return None;
        }

        let mut visited = vec![false; self.nodes.len()];
        let mut order = Vec::new();

        for i in 0..self.nodes.len() {
            if !visited[i] {
                self.topo_dfs(i, &mut visited, &mut order);
            }
        }

        order.reverse();
        Some(order)
    }

    fn topo_dfs(&self, u: usize, visited: &mut [bool], order: &mut Vec<N>) {
        visited[u] = true;
        for &v in &self.adjacency[u] {
            if !visited[v] {
                self.topo_dfs(v, visited, order);
            }
        }
        order.push(self.nodes[u].clone());
    }
}
```

### Solution to Exercise 3
```rust
impl<N: Clone + Eq + std::hash::Hash + std::fmt::Debug> Graph<N> {
    pub fn count_connected_components(&self) -> usize {
        let mut visited = vec![false; self.nodes.len()];
        let mut components = 0;

        for i in 0..self.nodes.len() {
            if !visited[i] {
                components += 1;
                let mut queue = VecDeque::new();
                visited[i] = true;
                queue.push_back(i);

                while let Some(curr) = queue.pop_front() {
                    for &neighbor in &self.adjacency[curr] {
                        if !visited[neighbor] {
                            visited[neighbor] = true;
                            queue.push_back(neighbor);
                        }
                    }
                }
            }
        }
        components
    }
}

fn main() {
    let mut g = Graph::new(false);
    g.add_edge("A", "B");
    g.add_edge("B", "C");
    g.add_edge("D", "E"); // Disconnected cluster

    assert_eq!(g.count_connected_components(), 2);

    let path = g.shortest_path(&"A", &"C");
    assert_eq!(path, Some(vec!["A", "B", "C"]));
    println!("All traversal exercises verified!");
}
```
