## Concept

In an unweighted graph, Breadth-First Search (BFS) finds the path with the fewest edges. However, in real-world systems (such as computer networks and road maps), edges have **weights** (e.g., latency in milliseconds, distance in kilometers, or transit cost in dollars).

**Dijkstra's Algorithm** solves the **Single-Source Shortest Path (SSSP)** problem for graphs with **non-negative edge weights**.

```
                [ Router A ]
               /            \
          5ms /              \ 20ms
             ▼                ▼
       [ Router B ] ────► [ Router C ]
             │      2ms       ▲
         4ms │                │ 1ms
             ▼                │
       [ Router D ] ──────────┘
```
*Note*: A naive BFS would pick path `A -> C` (1 hop, 20ms). Dijkstra finds the true optimal route `A -> B -> D -> C` (3 hops, total cost: $5 + 4 + 1 = 10\text{ms}$).

---

### 1. Algorithm Mechanics & Edge Relaxation

Dijkstra maintains:
1. A **Distances Array** `dist`: Initialized to $\infty$ (`usize::MAX`), with `dist[start] = 0`.
2. A **Min-Priority Queue**: Stores pairs of `(tentative_distance, node_id)`.
3. A **Predecessor Array** `parent`: Tracks the incoming node for path reconstruction.

#### The Edge Relaxation Step:
At each step, Dijkstra extracts the unvisited node $u$ with the smallest known distance. For each neighbor $v$ connected via edge weight $w$:
$$\text{If } \text{dist}[u] + w < \text{dist}[v] \implies \text{dist}[v] = \text{dist}[u] + w$$

```
Dijkstra Step-by-Step Execution:
1. Pop (0, A):
   - Relax A -> B (5ms): dist[B] = 5. Push (5, B)
   - Relax A -> C (20ms): dist[C] = 20. Push (20, C)
2. Pop (5, B):
   - Relax B -> C (2ms): 5 + 2 = 7ms < 20ms! dist[C] = 7. Push (7, C)
   - Relax B -> D (4ms): 5 + 4 = 9ms. dist[D] = 9. Push (9, D)
3. Pop (7, C):
   - No outgoing edges from C.
4. Pop (9, D):
   - Relax D -> C (1ms): 9 + 1 = 10ms (10 > 7, no change).
```

---

### 2. Time and Space Complexity

With an adjacency list and a binary heap:
- **Time Complexity**: **$O((V + E) \log V)$** (Each vertex is extracted from the heap once, and each edge relaxation pushes a new entry).
- **Space Complexity**: **$O(V)$** (To store the distance table, predecessor table, and heap items).

> [!WARNING]
> Dijkstra's algorithm requires **non-negative weights** ($w \ge 0$). If negative weights are present, greedy choices fail, and the **Bellman-Ford algorithm** must be used instead.

---

## Why it matters

- **Internet Routing Protocols**: OSPF (Open Shortest Path First) and IS-IS run Dijkstra's algorithm inside enterprise routers to direct IP packets along minimum-latency fiber links.
- **Service Mesh Traffic Routing**: Proxies like Envoy calculate lowest-cost paths between microservices based on dynamic endpoint latency metrics.
- **Geographic Navigation**: GPS systems (Google Maps, OpenStreetMap) use Dijkstra and $A^*$ search on continent-scale road networks.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::cmp::Ordering;
use std::collections::{BinaryHeap, HashMap};

// Represents an edge to a neighbor with a positive integer weight
#[derive(Debug, Clone)]
pub struct Edge {
    pub target: usize,
    pub cost: usize,
}

// State stored inside the Min-Priority Queue
#[derive(Copy, Clone, Eq, PartialEq)]
struct State {
    cost: usize,
    position: usize,
}

// Invert ordering so BinaryHeap acts as a Min-Heap instead of a Max-Heap
impl Ord for State {
    fn cmp(&self, other: &Self) -> Ordering {
        other.cost.cmp(&self.cost)
            .then_with(|| self.position.cmp(&other.position))
    }
}

impl PartialOrd for State {
    fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
        Some(self.cmp(other))
    }
}

#[derive(Debug)]
pub struct WeightedGraph {
    nodes: Vec<String>,
    lookup: HashMap<String, usize>,
    adjacency: Vec<Vec<Edge>>,
}

impl WeightedGraph {
    pub fn new() -> Self {
        WeightedGraph {
            nodes: Vec::new(),
            lookup: HashMap::new(),
            adjacency: Vec::new(),
        }
    }

    pub fn add_node(&mut self, name: &str) -> usize {
        if let Some(&idx) = self.lookup.get(name) {
            return idx;
        }
        let idx = self.nodes.len();
        self.lookup.insert(name.to_string(), idx);
        self.nodes.push(name.to_string());
        self.adjacency.push(Vec::new());
        idx
    }

    pub fn add_edge(&mut self, from: &str, to: &str, cost: usize) {
        let u = self.add_node(from);
        let v = self.add_node(to);
        self.adjacency[u].push(Edge { target: v, cost });
    }

    // Run Dijkstra from start_node. Returns (distances, predecessors)
    pub fn dijkstra(&self, start: &str) -> Option<(Vec<usize>, Vec<Option<usize>>)> {
        let &start_idx = self.lookup.get(start)?;

        let num_nodes = self.nodes.len();
        let mut dist = vec![usize::MAX; num_nodes];
        let mut parent = vec![None; num_nodes];
        let mut heap = BinaryHeap::new();

        dist[start_idx] = 0;
        heap.push(State {
            cost: 0,
            position: start_idx,
        });

        while let Some(State { cost, position }) = heap.pop() {
            // If we found a shorter path to `position` already, skip stale entry
            if cost > dist[position] {
                continue;
            }

            for edge in &self.adjacency[position] {
                let next_cost = cost + edge.cost;

                // Relaxation step
                if next_cost < dist[edge.target] {
                    dist[edge.target] = next_cost;
                    parent[edge.target] = Some(position);
                    heap.push(State {
                        cost: next_cost,
                        position: edge.target,
                    });
                }
            }
        }

        Some((dist, parent))
    }

    // Reconstruct the exact path between two node names
    pub fn shortest_path(&self, from: &str, to: &str) -> Option<(usize, Vec<String>)> {
        let (dist, parent) = self.dijkstra(from)?;
        let &end_idx = self.lookup.get(to)?;

        if dist[end_idx] == usize::MAX {
            return None; // Target unreachable
        }

        let mut path = Vec::new();
        let mut curr = Some(end_idx);
        while let Some(idx) = curr {
            path.push(self.nodes[idx].clone());
            curr = parent[idx];
        }
        path.reverse();

        Some((dist[end_idx], path))
    }
}

fn main() {
    let mut network = WeightedGraph::new();

    network.add_edge("NYC", "Chicago", 800);
    network.add_edge("NYC", "DC", 220);
    network.add_edge("DC", "Atlanta", 600);
    network.add_edge("Chicago", "Denver", 1000);
    network.add_edge("Atlanta", "Dallas", 780);
    network.add_edge("Dallas", "Denver", 650);
    network.add_edge("Denver", "SF", 1250);
    network.add_edge("Dallas", "SF", 1750);

    let (cost, path) = network.shortest_path("NYC", "SF").unwrap();
    println!("Shortest route from NYC to SF:");
    println!("Total Distance: {} miles", cost);
    println!("Route: {}", path.join(" ──► "));
}
```

## Common Mistakes

### 1. Forgetting to Skip Stale Queue Entries
Because Rust's `BinaryHeap` does not support an in-place `decrease_key` operation, improved distances are pushed as new entries into the heap. Without the check:
```rust
if cost > dist[position] {
    continue;
}
```
the algorithm will re-explore subgraphs with outdated, suboptimal distances, causing unnecessary work.

---

### 2. Inverting `Ord` Incorrectly for Min-Heap
Implementing `Ord` with `self.cost.cmp(&other.cost)` makes `BinaryHeap` pop the **largest** cost first (Max-Heap), producing incorrect paths. To create a Min-Heap, you must reverse the comparison: `other.cost.cmp(&self.cost)`.

---

### 3. Arithmetic Overflow with Infinity Sentinels
Using `usize::MAX` as infinity means adding `dist[u] + edge.cost` directly could overflow and wrap around or panic in debug mode. Always guard additions or check `dist[u] != usize::MAX` before adding.

impl WeightedGraph {
    pub fn shortest_path_early_exit(&self, from: &str, to: &str) -> Option<(usize, Vec<String>)> {
        let &start_idx = self.lookup.get(from)?;
        let &end_idx = self.lookup.get(to)?;

        let num_nodes = self.nodes.len();
        let mut dist = vec![usize::MAX; num_nodes];
        let mut parent = vec![None; num_nodes];
        let mut heap = BinaryHeap::new();

        dist[start_idx] = 0;
        heap.push(State { cost: 0, position: start_idx });

        while let Some(State { cost, position }) = heap.pop() {
            // Early exit as soon as target is finalized
            if position == end_idx {
                break;
            }

            if cost > dist[position] {
                continue;
            }

            for edge in &self.adjacency[position] {
                let next_cost = cost + edge.cost;
                if next_cost < dist[edge.target] {
                    dist[edge.target] = next_cost;
                    parent[edge.target] = Some(position);
                    heap.push(State { cost: next_cost, position: edge.target });
                }
            }
        }

        if dist[end_idx] == usize::MAX {
            return None;
        }

        let mut path = Vec::new();
        let mut curr = Some(end_idx);
        while let Some(idx) = curr {
            path.push(self.nodes[idx].clone());
            curr = parent[idx];
        }
        path.reverse();

        Some((dist[end_idx], path))
    }
}

impl WeightedGraph {
    pub fn multi_source_dijkstra(&self, sources: &[&str]) -> Vec<usize> {
        let num_nodes = self.nodes.len();
        let mut dist = vec![usize::MAX; num_nodes];
        let mut heap = BinaryHeap::new();

        for &src in sources {
            if let Some(&idx) = self.lookup.get(src) {
                dist[idx] = 0;
                heap.push(State { cost: 0, position: idx });
            }
        }

        while let Some(State { cost, position }) = heap.pop() {
            if cost > dist[position] {
                continue;
            }

            for edge in &self.adjacency[position] {
                let next_cost = cost + edge.cost;
                if next_cost < dist[edge.target] {
                    dist[edge.target] = next_cost;
                    heap.push(State { cost: next_cost, position: edge.target });
                }
            }
        }

        dist
    }
}

### Solution to Exercise 3
```rust
// In maximum bottleneck path, we maximize the minimum bandwidth
pub fn max_bottleneck_path(
    adjacency: &[Vec<(usize, usize)>],
    start: usize,
    end: usize,
    num_nodes: usize,
) -> Option<usize> {
    let mut max_cap = vec![0usize; num_nodes];
    let mut heap = BinaryHeap::new(); // Standard Max-Heap on capacity

    max_cap[start] = usize::MAX;
    heap.push((usize::MAX, start));

    while let Some((cap, u)) = heap.pop() {
        if u == end {
            return Some(cap);
        }
        if cap < max_cap[u] {
            continue;
        }

        for &(v, weight) in &adjacency[u] {
            let bottleneck = std::cmp::min(cap, weight);
            if bottleneck > max_cap[v] {
                max_cap[v] = bottleneck;
                heap.push((bottleneck, v));
            }
        }
    }

    None
}

fn main() {
    let mut g = WeightedGraph::new();
    g.add_edge("A", "B", 4);
    g.add_edge("A", "C", 2);
    g.add_edge("C", "B", 1);

    let (cost, path) = g.shortest_path_early_exit("A", "B").unwrap();
    assert_eq!(cost, 3); // Path A -> C -> B
    assert_eq!(path, vec!["A", "C", "B"]);
    println!("Dijkstra exercises verified successfully!");
}
```
