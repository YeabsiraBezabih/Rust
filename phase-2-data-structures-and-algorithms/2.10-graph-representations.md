## Concept

A **Graph** is a non-linear data structure consisting of a set of **Vertices** (or Nodes, $V$) connected by **Edges** (or Links, $E$). 

Unlike trees (which are strictly hierarchical and acyclic), graphs can model arbitrary networks with cycles, multiple paths, and bidirectional links.

```
       (A: Web Server)
         /         \
   10ms /           \ 25ms
       ▼             ▼
(B: Auth Service) ──► (C: Database)
       │       5ms
       │ 12ms
       ▼
(D: Cache Node)
```

---

### 1. Graph Classifications

- **Directed vs. Undirected**:
  - *Directed Graph (Digraph)*: Edges have a specific direction ($u \to v$, e.g., web hyperlinks or service dependencies).
  - *Undirected Graph*: Edges are bidirectional ($u \leftrightarrow v$, e.g., peer-to-peer connections).
- **Weighted vs. Unweighted**:
  - *Weighted Graph*: Edges carry numeric costs, latencies, or capacities ($A \xrightarrow{10\text{ms}} B$).
  - *Unweighted Graph*: Edges only denote existence of a link.
- **Dense vs. Sparse**:
  - *Dense Graph*: Number of edges is close to maximum possible ($E \approx V^2$).
  - *Sparse Graph*: Most pairs of nodes are not directly connected ($E \ll V^2$). Almost all real-world networks (road maps, web pages, social graphs) are sparse.

---

### 2. Representation 1: Adjacency Matrix

An **Adjacency Matrix** is a 2D array of size $|V| \times |V|$ where `matrix[u][v]` stores the edge weight (or a boolean flag):

```
       0    1    2
  0 [  0,  10,  25 ]
  1 [  0,   0,   5 ]
  2 [  0,   0,   0 ]
```

| Metric | Complexity | Note |
| :--- | :--- | :--- |
| **Space** | $O(V^2)$ | Prohibitive for large sparse graphs ($10^5$ nodes $= 10\text{ GB}$). |
| **Edge Lookup** (`has_edge(u, v)`) | $O(1)$ | Direct memory offset indexing. |
| **Find All Neighbors of $u$** | $O(V)$ | Must scan entire row of length $V$. |

---

### 3. Representation 2: Adjacency List

An **Adjacency List** stores an array or vector of lists. Each index $u$ points directly to a list of its outgoing neighbors:

```
Index (Node):     Outgoing Neighbors:
  0 (Web)     ──► [ (1, 10ms), (2, 25ms) ]
  1 (Auth)    ──► [ (2, 5ms), (3, 12ms) ]
  2 (DB)      ──► [ ]
  3 (Cache)   ──► [ ]
```

| Metric | Complexity | Note |
| :--- | :--- | :--- |
| **Space** | $O(V + E)$ | Optimal for sparse graphs; only stores real connections. |
| **Edge Lookup** (`has_edge(u, v)`) | $O(\text{deg}(u))$ | Linear scan through the neighbors of node $u$. |
| **Find All Neighbors of $u$** | $O(\text{deg}(u))$ | Instant access to the exact slice of neighbors. |

---

## Why it matters

- **Build Systems**: Cargo, Make, and Bazel use Directed Acyclic Graphs (DAGs) to track crate compilation dependencies and parallelize compilation jobs.
- **Network Packet Routing**: Internet routers running BGP and OSPF protocols maintain adjacency lists of network topologies to compute optimal routing paths.
- **Garbage Collection**: Tracing GC engines traverse graphs of heap object references to identify and reclaim unreachable memory cycles.

---

## Analogy

- **Adjacency Matrix**: A massive wall calendar with a grid for every person in a company. You check if Alice talks to Bob by looking at row "Alice" and column "Bob" (mostly blank cells).
- **Adjacency List**: Alice's personal phone address book. It lists only the specific people she actually calls.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::collections::HashMap;

// Represents an edge to a target node with an associated weight
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Edge<W> {
    pub target: usize,
    pub weight: W,
}

// Graph backed by an Adjacency List with labeled vertices
#[derive(Debug, Clone)]
pub struct Graph<N, W> {
    nodes: Vec<N>,                  // Node index -> Node payload
    node_lookup: HashMap<N, usize>, // Node payload -> Node index
    adjacency: Vec<Vec<Edge<W>>>,   // Node index -> List of outgoing edges
    is_directed: bool,
}

impl<N: Clone + Eq + std::hash::Hash, W: Clone> Graph<N, W> {
    pub fn new(is_directed: bool) -> Self {
        Graph {
            nodes: Vec::new(),
            node_lookup: HashMap::new(),
            adjacency: Vec::new(),
            is_directed,
        }
    }

    // Register a new node or return its existing index
    pub fn add_node(&mut self, node: N) -> usize {
        if let Some(&index) = self.node_lookup.get(&node) {
            return index;
        }

        let index = self.nodes.len();
        self.node_lookup.insert(node.clone(), index);
        self.nodes.push(node);
        self.adjacency.push(Vec::new());
        index
    }

    // Add an edge between two node payloads
    pub fn add_edge(&mut self, from: N, to: N, weight: W) {
        let u = self.add_node(from);
        let v = self.add_node(to);

        self.adjacency[u].push(Edge {
            target: v,
            weight: weight.clone(),
        });

        if !self.is_directed {
            self.adjacency[v].push(Edge {
                target: u,
                weight,
            });
        }
    }

    pub fn node_count(&self) -> usize {
        self.nodes.len()
    }

    pub fn edge_count(&self) -> usize {
        let total: usize = self.adjacency.iter().map(|edges| edges.len()).sum();
        if self.is_directed {
            total
        } else {
            total / 2
        }
    }

    // Get all outgoing edges from a node
    pub fn neighbors(&self, node: &N) -> Option<&[Edge<W>]> {
        let &idx = self.node_lookup.get(node)?;
        Some(&self.adjacency[idx])
    }

    // Get the payload for a given node index
    pub fn get_node_label(&self, index: usize) -> Option<&N> {
        self.nodes.get(index)
    }
}

fn main() {
    // Construct a directed microservice latency network
    let mut network: Graph<&str, u32> = Graph::new(true);

    network.add_edge("gateway", "auth_service", 12);
    network.add_edge("gateway", "payment_service", 45);
    network.add_edge("auth_service", "user_db", 4);
    network.add_edge("payment_service", "bank_api", 120);

    println!("Total nodes: {}", network.node_count());
    println!("Total edges: {}", network.edge_count());

    // Inspect outgoing dependencies from gateway
    if let Some(neighbors) = network.neighbors(&"gateway") {
        println!("Gateway outgoing routes:");
        for edge in neighbors {
            let target_name = network.get_node_label(edge.target).unwrap();
            println!("  ──► {} (latency: {}ms)", target_name, edge.weight);
        }
    }
}
```

## Common Mistakes

### 1. Allocating an Adjacency Matrix for Large Sparse Networks
Attempting `let mut matrix = vec![vec![0; 100_000]; 100_000];` creates a 10-billion entry matrix requiring tens of gigabytes of RAM, causing an instant Out-Of-Memory (OOM) crash. Always use an Adjacency List for sparse graphs.

---

### 2. Forgetting Symmetric Edges in Undirected Graphs
Inserting an edge `(u, v)` into an undirected graph without also inserting `(v, u)`. This breaks pathfinding algorithms because the node appears unreachable from the opposite direction.

---

### 3. Borrowing Collisions When Mutating Graph State
Trying to iterate over `self.adjacency[u]` while simultaneously calling a method that mutates `&mut self`. Always decouple node lookups or clone the edge indices before mutating the graph.

## Solutions

### Solution to Exercise 1
```rust
impl<N: Clone + Eq + std::hash::Hash, W: Clone> Graph<N, W> {
    pub fn out_degree(&self, node: &N) -> Option<usize> {
        let &idx = self.node_lookup.get(node)?;
        Some(self.adjacency[idx].len())
    }

    pub fn in_degree(&self, node: &N) -> Option<usize> {
        let &target_idx = self.node_lookup.get(node)?;
        let count = self.adjacency
            .iter()
            .flat_map(|edges| edges.iter())
            .filter(|edge| edge.target == target_idx)
            .count();
        Some(count)
    }
}
```

### Solution to Exercise 2
```rust
impl<N: Clone + Eq + std::hash::Hash, W: Clone> Graph<N, W> {
    pub fn transpose(&self) -> Graph<N, W> {
        let mut reversed = Graph::new(self.is_directed);
        for node in &self.nodes {
            reversed.add_node(node.clone());
        }

        for (u, edges) in self.adjacency.iter().enumerate() {
            let u_label = &self.nodes[u];
            for edge in edges {
                let v_label = &self.nodes[edge.target];
                // Invert edge: v -> u
                reversed.add_edge(v_label.clone(), u_label.clone(), edge.weight.clone());
            }
        }
        reversed
    }
}
```

---

### Solution to Exercise 3
```rust
impl<N: Clone + Eq + std::hash::Hash, W: Clone> Graph<N, W> {
    pub fn to_adjacency_matrix(&self) -> Vec<Vec<Option<W>>> {
        let n = self.nodes.len();
        let mut matrix = vec![vec![None; n]; n];

        for (u, edges) in self.adjacency.iter().enumerate() {
            for edge in edges {
                matrix[u][edge.target] = Some(edge.weight.clone());
            }
        }
        matrix
    }
}

fn main() {
    let mut g: Graph<&str, u32> = Graph::new(true);
    g.add_edge("A", "B", 10);
    g.add_edge("A", "C", 20);
    g.add_edge("B", "C", 30);

    assert_eq!(g.out_degree(&"A"), Some(2));
    assert_eq!(g.in_degree(&"C"), Some(2));

    let transposed = g.transpose();
    assert_eq!(transposed.out_degree(&"C"), Some(2));

    let matrix = g.to_adjacency_matrix();
    assert_eq!(matrix[0][1], Some(10));
    assert_eq!(matrix[0][2], Some(20));
    assert_eq!(matrix[1][0], None);
    println!("All graph representation tests passed!");
}
```
