## Concept

Rust provides low-level, high-performance networking primitives directly in its standard library through `std::net`:
- **`TcpListener`**: Binds to a local port and listens for incoming client connection requests.
- **`TcpStream`**: Represents an active, established full-duplex TCP socket between two endpoints.

```
Server Side:
1. TcpListener::bind("127.0.0.1:8080")
          │
2. listener.incoming() (Blocks waiting for client handshake)
          │
          ▼ ─── Client connects! ───
3. Returns established `TcpStream`
          │
          ├──► stream.read(&mut buffer)   (Receives bytes from client)
          └──► stream.write_all(&data)    (Sends bytes to client)
```

---

### 1. `TcpListener` Mechanics

When you call `TcpListener::bind("127.0.0.1:8080")`:
1. The operating system allocates a listening socket file descriptor.
2. The kernel manages the TCP 3-way handshake queue in the background.
3. Calling `listener.incoming()` returns an iterator yielding `Result<TcpStream, io::Error>` whenever a new connection completes the handshake.

---

### 2. `TcpStream` and the `Read`/`Write` Traits

`TcpStream` implements both `std::io::Read` and `std::io::Write`:

#### Reading Data:
```rust
let mut buffer = [0u8; 1024];
let bytes_read = stream.read(&mut buffer)?;
```
- **`bytes_read > 0`**: Successfully read bytes into `buffer[0..bytes_read]`.
- **`bytes_read == 0` (EOF)**: The client closed the connection. **You must break out of the loop and drop the stream!**

#### Writing Data:
```rust
stream.write_all(b"Hello from Rust TCP Server\n")?;
stream.flush()?; // Ensures kernel transmits buffered packets immediately
```

---

### 3. Socket Configuration: Low-Latency and Timeouts

- **`stream.set_nodelay(true)`**: Disables **Nagle's Algorithm** (which buffers small packets to reduce header overhead). This reduces packet latency from ~40ms to microseconds for real-time systems.
- **`stream.set_read_timeout(Some(Duration::from_secs(5)))`**: Prevents unresponsive clients from hanging worker threads indefinitely (**Slowloris Attack prevention**).

---

## Why it matters

- **Writing Custom Network Protocols**: Custom Redis-compatible caches, MQTT brokers for IoT devices, and real-time multiplayer game servers are built directly on top of `TcpListener` and `TcpStream`.
- **Zero-Dependency Core**: You do not need third-party dependencies to build fully functional network servers in Rust.

## Analogy

- **`TcpStream`**: The direct two-way phone line between the front desk and the guest's room. Both sides can speak (`write`) and listen (`read`) simultaneously.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::io::{Read, Write};
use std::net::{TcpListener, TcpStream};
use std::thread;
use std::time::Duration;

// Handles a single connected client socket
fn handle_client(mut stream: TcpStream) {
    let peer_addr = stream.peer_addr().unwrap();
    println!("[Server] New connection from: {}", peer_addr);

    // Set a 5-second read timeout for security
    stream.set_read_timeout(Some(Duration::from_secs(5))).unwrap();
    // Disable Nagle's algorithm for instant packet delivery
    stream.set_nodelay(true).unwrap();

    let mut buffer = [0u8; 512];

    loop {
        match stream.read(&mut buffer) {
            Ok(0) => {
                // EOF: Client disconnected cleanly
                println!("[Server] Client {} closed connection.", peer_addr);
                break;
            }
            Ok(bytes_read) => {
                let received_text = String::from_utf8_lossy(&buffer[..bytes_read]);
                print!("[Server] Received from {}: {}", peer_addr, received_text);

                // Echo back with a prefix
                let response = format!("ECHO: {}", received_text);
                if let Err(e) = stream.write_all(response.as_bytes()) {
                    eprintln!("[Server] Failed to write to {}: {}", peer_addr, e);
                    break;
                }
                stream.flush().unwrap();
            }
            Err(e) => {
                eprintln!("[Server] Read error on {}: {}", peer_addr, e);
                break;
            }
        }
    }
}

// Client simulator to test the server
fn run_client_test(port: u16) {
    // Wait for server to start
    thread::sleep(Duration::from_millis(50));

    let mut client = TcpStream::connect(format!("127.0.0.1:{}", port)).unwrap();
    println!("[Client] Connected to server successfully.");

    // Send a message
    client.write_all(b"Hello Rust TCP Server!\n").unwrap();
    client.flush().unwrap();

    // Read echo response
    let mut response_buf = [0u8; 512];
    let n = client.read(&mut response_buf).unwrap();
    let response_text = String::from_utf8_lossy(&response_buf[..n]);
    println!("[Client] Server echoed back: {}", response_text.trim());

    assert!(response_text.contains("ECHO: Hello Rust TCP Server!"));
}

fn main() {
    let port = 7878;
    let listener = TcpListener::bind(format!("127.0.0.1:{}", port)).unwrap();
    println!("=== TCP Echo Server listening on 127.0.0.1:{} ===", port);

    // Spawn a test client in a background thread
    thread::spawn(move || {
        run_client_test(port);
    });

    // Accept incoming connection (single-connection test mode)
    if let Some(stream) = listener.incoming().next() {
        match stream {
            Ok(stream) => handle_client(stream),
            Err(e) => eprintln!("Accept error: {}", e),
        }
    }

    println!("TCP Server demonstration finished.");
}
```

## Common Mistakes

### 1. Infinite Busy-Looping on EOF (`bytes_read == 0`)
When a client disconnects, `stream.read()` does not return an error; it returns `Ok(0)`.
```rust
// ❌ CRITICAL BUG: 100% CPU spinning forever on disconnect!
while let Ok(n) = stream.read(&mut buf) {
    stream.write_all(&buf[..n])?;
}

// ✅ CORRECT: Explicitly check for 0 bytes (EOF) and break
match stream.read(&mut buf) {
    Ok(0) => break, // Disconnected
    Ok(n) => stream.write_all(&buf[..n])?,
    Err(e) => break,
}
```

---

### 2. Forgetting `stream.flush()`
When writing small buffers, the OS kernel TCP stack may hold data in memory waiting for more bytes. Always call `stream.flush()` to force immediate packet transmission.

---

### 3. Missing Connection Timeouts
Without `set_read_timeout()`, a client that connects and sends zero bytes will hold the thread open forever, exhausting server resources.

## Solutions

### Solution to Exercise 1
```rust
use std::io::{Read, Write};
use std::net::TcpStream;

pub fn handle_uppercase_client(mut stream: TcpStream) {
    let mut buffer = [0u8; 512];
    while let Ok(n) = stream.read(&mut buffer) {
        if n == 0 { break; }
        let upper: Vec<u8> = buffer[..n].iter().map(|b| b.to_ascii_uppercase()).collect();
        stream.write_all(&upper).unwrap();
        stream.flush().unwrap();
    }
}
```

---

### Solution to Exercise 2
```rust
pub fn handle_command_protocol(mut stream: TcpStream) {
    let mut buffer = [0u8; 512];
    loop {
        match stream.read(&mut buffer) {
            Ok(0) => break,
            Ok(n) => {
                let cmd = String::from_utf8_lossy(&buffer[..n]).trim().to_string();
                match cmd.as_str() {
                    "PING" => {
                        stream.write_all(b"PONG\n").unwrap();
                    }
                    "QUIT" => {
                        stream.write_all(b"BYE\n").unwrap();
                        break;
                    }
                    _ => {
                        stream.write_all(b"ERR: Unknown command\n").unwrap();
                    }
                }
                stream.flush().unwrap();
            }
            Err(_) => break,
        }
    }
}
```

### Solution to Exercise 3
```rust
use std::net::TcpListener;
use std::thread;

pub fn run_multithreaded_server(listener: TcpListener) {
    for stream in listener.incoming() {
        match stream {
            Ok(socket) => {
                thread::spawn(move || {
                    handle_uppercase_client(socket);
                });
            }
            Err(e) => eprintln!("Connection accept error: {}", e),
        }
    }
}

fn main() {
    let listener = TcpListener::bind("127.0.0.1:0").unwrap();
    let addr = listener.local_addr().unwrap();

    thread::spawn(move || {
        if let Ok((mut client, _)) = listener.accept() {
            handle_command_protocol(client);
        }
    });

    let mut client = TcpStream::connect(addr).unwrap();
    client.write_all(b"PING\n").unwrap();
    let mut resp = [0u8; 16];
    let n = client.read(&mut resp).unwrap();
    assert_eq!(&resp[..n], b"PONG\n");
    println!("All TCP socket exercises verified successfully!");
}
```
