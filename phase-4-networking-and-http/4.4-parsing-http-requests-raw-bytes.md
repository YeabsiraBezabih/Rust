# Lesson 4.4: Parsing HTTP Requests by Hand from Raw Byte Buffers

## Concept

When an HTTP request arrives on a TCP socket, it enters user-space memory as a flat array of bytes (`&[u8]`).

Many high-level frameworks convert these bytes into hundreds of small heap-allocated `String` instances. In systems programming, we use **Zero-Copy Parsing**: our `Request<'a>` struct borrows string and byte slices **directly from the original socket buffer** without a single heap allocation.

```
Incoming TCP Byte Buffer in RAM:
┌────────────────────────────────────────────────────────────────────────┐
│ GET /users?id=42 HTTP/1.1\r\nHost: example.com\r\n\r\n[Body Bytes...]   │
└────────────────────────────────────────────────────────────────────────┘
  │   │                │     │     │            │   │
  │   └── path: &'a str│     │     └── val: &'a str └── body: &'a [u8]
  └────── method: Method     └──────── key: &'a str
```

---

### 1. Step-by-Step Parsing Algorithm

1. **Locate the Header-Body Boundary**: Scan the raw buffer for the double CRLF delimiter (`\r\n\r\n` / `[13, 10, 13, 10]`). If absent, the request is incomplete — wait for more TCP packets.
2. **Split Header Section**: Split the bytes preceding `\r\n\r\n` by `\r\n`.
3. **Parse Request Line**:
   - First line: `METHOD PATH VERSION`.
   - Separate the URI path from optional query strings (`/search?q=rust`).
4. **Parse Header Lines**:
   - For each subsequent line, split on the **first colon (`:`)** only.
   - Trim leading and trailing whitespace from the key and value.
5. **Verify and Extract Message Body**:
   - Inspect the `Content-Length` header (if present).
   - Slice the body bytes from `header_end + 4` to `header_end + 4 + content_length`.

---

### 2. The Zero-Copy Request Struct

```rust
#[derive(Debug)]
pub struct HttpRequest<'a> {
    pub method: &'a str,
    pub path: &'a str,
    pub query_string: Option<&'a str>,
    pub headers: Vec<(&'a str, &'a str)>,
    pub body: &'a [u8],
}
```
All fields carry lifetime `'a`, guaranteeing they reference the underlying socket buffer without memory duplication.

---

## Why it matters

- **Extreme Throughput**: Zero-copy HTTP parsing allows modern Rust proxies (like Pingora and Cloudflare Workers) to process millions of requests per second per CPU core without triggering memory allocation locks.
- **Cache Locality**: Parsing within a single contiguous buffer keeps data in CPU L1/L2 data caches.

---

## Analogy

Think of **Highlighting Text in a Textbook**:
- A naive parser photocopies every paragraph onto a separate index card (heap allocation).
- A zero-copy parser places color-coded transparent bookmarks in the original book (borrowed references). It uses zero paper and is instantaneous.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::collections::HashMap;

#[derive(Debug, PartialEq, Eq)]
pub struct HttpRequest<'a> {
    pub method: &'a str,
    pub path: &'a str,
    pub query_string: Option<&'a str>,
    pub headers: Vec<(&'a str, &'a str)>,
    pub body: &'a [u8],
}

#[derive(Debug, PartialEq, Eq)]
pub enum HttpParseError {
    Incomplete,
    MalformedRequestLine,
    InvalidHeader,
    InvalidContentLength,
    InvalidUtf8,
}

impl<'a> HttpRequest<'a> {
    pub fn parse(buffer: &'a [u8]) -> Result<Self, HttpParseError> {
        // Step 1: Find double CRLF delimiter (\r\n\r\n)
        let header_end = buffer
            .windows(4)
            .position(|w| w == b"\r\n\r\n")
            .ok_or(HttpParseError::Incomplete)?;

        let header_bytes = &buffer[..header_end];
        let body_bytes = &buffer[header_end + 4..];

        // Convert header bytes to UTF-8 str
        let header_str = std::str::from_utf8(header_bytes)
            .map_err(|_| HttpParseError::InvalidUtf8)?;

        let mut lines = header_str.split("\r\n");

        // Step 2: Parse Request Line (e.g. "GET /search?q=rust HTTP/1.1")
        let request_line = lines.next().ok_or(HttpParseError::MalformedRequestLine)?;
        let mut request_line_parts = request_line.split_whitespace();

        let method = request_line_parts
            .next()
            .ok_or(HttpParseError::MalformedRequestLine)?;
        let full_path = request_line_parts
            .next()
            .ok_or(HttpParseError::MalformedRequestLine)?;
        let version = request_line_parts
            .next()
            .ok_or(HttpParseError::MalformedRequestLine)?;

        if version != "HTTP/1.1" && version != "HTTP/1.0" {
            return Err(HttpParseError::MalformedRequestLine);
        }

        // Separate Path and Query String
        let (path, query_string) = match full_path.split_once('?') {
            Some((p, q)) => (p, Some(q)),
            None => (full_path, None),
        };

        // Step 3: Parse Headers
        let mut headers = Vec::new();
        let mut content_length: usize = 0;

        for line in lines {
            if line.is_empty() {
                continue;
            }
            let (key, val) = line
                .split_once(':')
                .ok_or(HttpParseError::InvalidHeader)?;

            let key_trimmed = key.trim();
            let val_trimmed = val.trim();

            if key_trimmed.eq_ignore_ascii_case("content-length") {
                content_length = val_trimmed
                    .parse::<usize>()
                    .map_err(|_| HttpParseError::InvalidContentLength)?;
            }

            headers.push((key_trimmed, val_trimmed));
        }

        // Step 4: Verify Body Length
        if body_bytes.len() < content_length {
            return Err(HttpParseError::Incomplete);
        }

        let body = &body_bytes[..content_length];

        Ok(HttpRequest {
            method,
            path,
            query_string,
            headers,
            body,
        })
    }

    // Helper: Lookup header by name (case-insensitive)
    pub fn get_header(&self, key: &str) -> Option<&'a str> {
        self.headers
            .iter()
            .find(|(k, _)| k.eq_ignore_ascii_case(key))
            .map(|(_, v)| *v)
    }

    // Helper: Parse URL query parameters into key-value map
    pub fn parse_query_params(&self) -> HashMap<&'a str, &'a str> {
        let mut params = HashMap::new();
        if let Some(qs) = self.query_string {
            for pair in qs.split('&') {
                if let Some((k, v)) = pair.split_once('=') {
                    params.insert(k, v);
                }
            }
        }
        params
    }
}

fn main() {
    let raw_post_request = b"\
POST /api/v1/orders?priority=high&source=web HTTP/1.1\r\n\
Host: checkout.example.com\r\n\
User-Agent: Mozilla/5.0\r\n\
Content-Type: application/json\r\n\
Content-Length: 29\r\n\
\r\n\
{\"order_id\":1001,\"total\":99.5}";

    println!("--- Parsing Raw HTTP Request ---");
    let req = HttpRequest::parse(raw_post_request).unwrap();

    println!("Method       : {}", req.method);
    println!("Path         : {}", req.path);
    println!("Query String : {:?}", req.query_string);
    println!("Content-Type : {:?}", req.get_header("content-type"));
    println!("Host         : {:?}", req.get_header("HOST")); // Case-insensitive!
    println!("Body Payload : {}", String::from_utf8_lossy(req.body));

    let query_params = req.parse_query_params();
    println!("Query Params : {:?}", query_params);
    assert_eq!(query_params.get("priority"), Some(&"high"));
}
```

---

## Common Mistakes

### 1. Splitting Headers with `line.split(':')` Instead of `split_once(':')`
Header values can contain colons (e.g., `Host: localhost:8080` or `Date: Sun, 06 Nov 1994 08:49:37 GMT`). Splitting on all colons breaks the value into invalid fragments. Always use `split_once(':')`.

---

### 2. Rejecting Requests Due to Case-Sensitive Header Lookups
Looking up `"content-length"` with `headers.get("Content-Length")` fails if the client sends lowercase or capitalized variations. Always use `.eq_ignore_ascii_case()`.

---

### 3. Converting the Entire Buffer to String Before Slicing the Body
HTTP request bodies can contain raw binary data (e.g. image uploads, gzip compressed bytes). Attempting `std::str::from_utf8(full_buffer)` will return an error on binary bodies. **Only parse the headers as UTF-8; keep the body as `&[u8]`.**

## Solutions

### Solution to Exercise 1
```rust
impl<'a> HttpRequest<'a> {
    pub fn get_query_param(&self, target_key: &str) -> Option<&'a str> {
        let qs = self.query_string?;
        for pair in qs.split('&') {
            if let Some((k, v)) = pair.split_once('=') {
                if k == target_key {
                    return Some(v);
                }
            }
        }
        None
    }
}
```

---

### Solution to Exercise 2
```rust
impl<'a> HttpRequest<'a> {
    pub fn parse_cookies(&self) -> Vec<(&'a str, &'a str)> {
        let mut cookies = Vec::new();
        if let Some(cookie_hdr) = self.get_header("cookie") {
            for item in cookie_hdr.split(';') {
                if let Some((k, v)) = item.trim().split_once('=') {
                    cookies.push((k.trim(), v.trim()));
                }
            }
        }
        cookies
    }
}
```

### Solution to Exercise 3
```rust
fn test_incomplete_read() {
    let fragmented_bytes = b"GET /index.html HTTP/1.1\r\nHost: loc";
    let res = HttpRequest::parse(fragmented_bytes);
    assert_eq!(res, Err(HttpParseError::Incomplete));
}

fn main() {
    let req_bytes = b"\
GET /dashboard?tab=analytics&range=30d HTTP/1.1\r\n\
Host: cloud.example.com\r\n\
Cookie: session_token=secret99; dark_mode=1\r\n\
\r\n";

    let req = HttpRequest::parse(req_bytes).unwrap();
    assert_eq!(req.get_query_param("tab"), Some("analytics"));
    assert_eq!(req.get_query_param("range"), Some("30d"));
    assert_eq!(req.get_query_param("missing"), None);

    let cookies = req.parse_cookies();
    assert_eq!(cookies, vec![("session_token", "secret99"), ("dark_mode", "1")]);

    test_incomplete_read();
    println!("All zero-copy HTTP parser exercises verified!");
}
```
