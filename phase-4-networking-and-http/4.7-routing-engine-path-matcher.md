## Concept

A **Router** is the traffic dispatcher of a web framework. It matches an incoming HTTP request's `(Method, Path)` tuple and invokes the corresponding **Handler Function**, extracting dynamic path parameters along the way.

```
Incoming Request: GET /api/v1/users/42/orders
                        │
                        ▼ (Segment-by-Segment Path Matcher)
[api] ──► [v1] ──► [users] ──► [:user_id] ──► [orders]
                                    │
                                    └── Extracted Param: user_id = "42"
                                    └── Invokes: get_user_orders_handler()
```

---

### 1. Types of URL Route Patterns

1. **Exact Matches**: `/health`, `/api/v1/metrics`.
2. **Parameterized Matches**: `/users/:id` (where `:id` matches any single segment like `42` or `alice`).
3. **Wildcard / Catch-All Matches**: `/static/*filepath` (matches everything remaining, e.g. `css/theme/dark.css`).

---

### 2. Segment-Based Prefix Tree (Trie) Routing

While small servers can use a linear list of regexes ($O(N \times \text{length})$), production web engines (like Axum, Actix, and Fastify) organize routes into a **Segment Tree (Trie)**:
- Paths are split by `/` into a sequence of segments.
- Traversal runs in **$O(K)$ time**, where $K$ is the number of segments in the request path, regardless of whether there are 10 or 10,000 registered routes.

---

### 3. Handler Signature and Path Parameters

```rust
pub type PathParams = std::collections::HashMap<String, String>;

pub type Handler = Box<
    dyn Fn(&HttpRequest, &PathParams) -> HttpResponse + Send + Sync + 'static
>;
```

---

## Why it matters

- **Zero-Regex Overhead**: Segment tree matching avoids heavy regular expression compilation and backtracking.
- **RESTful API Ergonomics**: Dynamic URL parameters (`/orgs/:org/repos/:repo/issues/:id`) allow expressive REST API designs.

---

## Analogy

Think of an **Automated Phone Directory**:
- Dialing `1` selects "Customer Service" (`/service`).
- Dialing `1` then `4` selects "Billing for Account #4" (`/service/:account_id`).
- You navigate one branch at a time until you reach the exact operator.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::collections::HashMap;

// Simplified Request & Response models from previous lessons
#[derive(Debug)]
pub struct HttpRequest<'a> {
    pub method: &'a str,
    pub path: &'a str,
}

#[derive(Debug, PartialEq, Eq)]
pub struct HttpResponse {
    pub status: u16,
    pub body: String,
}

impl HttpResponse {
    pub fn ok(body: &str) -> Self {
        HttpResponse { status: 200, body: body.to_string() }
    }
    pub fn not_found() -> Self {
        HttpResponse { status: 404, body: "404 Not Found".to_string() }
    }
}

pub type PathParams = HashMap<String, String>;
pub type Handler = Box<dyn Fn(&HttpRequest, &PathParams) -> HttpResponse + Send + Sync + 'static>;

// Represents a pattern segment in a route definition
#[derive(Debug, Clone, PartialEq, Eq)]
enum Segment {
    Literal(String), // e.g. "users"
    Param(String),   // e.g. ":id"
    Wildcard(String),// e.g. "*filepath"
}

struct Route {
    method: String,
    segments: Vec<Segment>,
    handler: Handler,
}

pub struct Router {
    routes: Vec<Route>,
}

impl Router {
    pub fn new() -> Self {
        Router { routes: Vec::new() }
    }

    // Register a route with method, path pattern, and closure handler
    pub fn add_route<F>(&mut self, method: &str, pattern: &str, handler: F)
    where
        F: Fn(&HttpRequest, &PathParams) -> HttpResponse + Send + Sync + 'static,
    {
        let segments = Self::parse_pattern(pattern);
        self.routes.push(Route {
            method: method.to_ascii_uppercase(),
            segments,
            handler: Box::new(handler),
        });
    }

    fn parse_pattern(pattern: &str) -> Vec<Segment> {
        pattern
            .split('/')
            .filter(|s| !s.is_empty())
            .map(|seg| {
                if let Some(param_name) = seg.strip_prefix(':') {
                    Segment::Param(param_name.to_string())
                } else if let Some(wildcard_name) = seg.strip_prefix('*') {
                    Segment::Wildcard(wildcard_name.to_string())
                } else {
                    Segment::Literal(seg.to_string())
                }
            })
            .collect()
    }

    // Match an incoming request against registered routes
    pub fn dispatch(&self, req: &HttpRequest) -> HttpResponse {
        let req_segments: Vec<&str> = req
            .path
            .split('/')
            .filter(|s| !s.is_empty())
            .collect();

        for route in &self.routes {
            if route.method != req.method.to_ascii_uppercase() {
                continue;
            }

            if let Some(params) = Self::match_segments(&route.segments, &req_segments) {
                return (route.handler)(req, &params);
            }
        }

        HttpResponse::not_found()
    }

    fn match_segments(pattern: &[Segment], actual: &[&str]) -> Option<PathParams> {
        let mut params = HashMap::new();
        let mut actual_idx = 0;

        for (p_idx, seg) in pattern.iter().enumerate() {
            match seg {
                Segment::Literal(lit) => {
                    if actual_idx >= actual.len() || actual[actual_idx] != lit {
                        return None;
                    }
                    actual_idx += 1;
                }
                Segment::Param(name) => {
                    if actual_idx >= actual.len() {
                        return None;
                    }
                    params.insert(name.clone(), actual[actual_idx].to_string());
                    actual_idx += 1;
                }
                Segment::Wildcard(name) => {
                    // Wildcard consumes all remaining segments
                    if actual_idx >= actual.len() {
                        params.insert(name.clone(), String::new());
                    } else {
                        let remaining = actual[actual_idx..].join("/");
                        params.insert(name.clone(), remaining);
                        actual_idx = actual.len();
                    }
                    break;
                }
            }
        }

        // Must match entire path unless ends with wildcard
        if actual_idx == actual.len() {
            Some(params)
        } else {
            None
        }
    }
}

fn main() {
    let mut router = Router::new();

    // 1. Register Exact Route
    router.add_route("GET", "/health", |_req, _params| {
        HttpResponse::ok("OK")
    });

    // 2. Register Parameterized Route
    router.add_route("GET", "/api/v1/users/:user_id", |_req, params| {
        let uid = params.get("user_id").unwrap();
        HttpResponse::ok(&format!("User Details for ID: {}", uid))
    });

    // 3. Register Wildcard Asset Route
    router.add_route("GET", "/static/*filepath", |_req, params| {
        let file = params.get("filepath").unwrap();
        HttpResponse::ok(&format!("Serving static asset: {}", file))
    });

    println!("--- Testing Route Dispatcher ---");

    // Test 1: Exact match
    let req1 = HttpRequest { method: "GET", path: "/health" };
    assert_eq!(router.dispatch(&req1), HttpResponse::ok("OK"));

    // Test 2: Dynamic parameter extraction
    let req2 = HttpRequest { method: "GET", path: "/api/v1/users/994" };
    let resp2 = router.dispatch(&req2);
    println!("Response 2: {:?}", resp2);
    assert_eq!(resp2, HttpResponse::ok("User Details for ID: 994"));

    // Test 3: Wildcard path
    let req3 = HttpRequest { method: "GET", path: "/static/images/logo.png" };
    let resp3 = router.dispatch(&req3);
    assert_eq!(resp3, HttpResponse::ok("Serving static asset: images/logo.png"));

    // Test 4: 404 Route
    let req4 = HttpRequest { method: "GET", path: "/unknown" };
    assert_eq!(router.dispatch(&req4), HttpResponse::not_found());
    println!("All router dispatch tests passed successfully!");
}
```

## Common Mistakes

### 1. Registering Specific Routes After Parametric Catch-Alls
If routes are tested sequentially:
- Route 1: `/users/:id`
- Route 2: `/users/me`
A request for `/users/me` matches Route 1 with `:id = "me"`!
*Fix*: Sort routes so literal segments are evaluated before parametric segments.

---

### 2. Failing to Strip Leading and Trailing Slashes
Assuming `/users` and `/users/` will match automatically. Splitting on `/` and filtering out empty segments (`!s.is_empty()`) normalizes slash variances seamlessly.

---

### 3. Case-Sensitive Method Matching
Comparing `route.method == req.method` when one is `"get"` and the other is `"GET"`. Always convert methods to uppercase before matching.

### Solution to Exercise 2
```rust
#[derive(Debug, PartialEq, Eq)]
pub enum DispatchResult {
    Handled(HttpResponse),
    MethodNotAllowed(Vec<String>),
    NotFound,
}

impl Router {
    pub fn dispatch_strict(&self, req: &HttpRequest) -> DispatchResult {
        let req_segments: Vec<&str> = req.path.split('/').filter(|s| !s.is_empty()).collect();
        let mut matched_methods = Vec::new();

        for route in &self.routes {
            if let Some(params) = Self::match_segments(&route.segments, &req_segments) {
                if route.method == req.method.to_ascii_uppercase() {
                    return DispatchResult::Handled((route.handler)(req, &params));
                } else {
                    matched_methods.push(route.method.clone());
                }
            }
        }

        if !matched_methods.is_empty() {
            DispatchResult::MethodNotAllowed(matched_methods)
        } else {
            DispatchResult::NotFound
        }
    }
}
```

fn test_multiple_params() {
    let mut router = Router::new();
    router.get("/orgs/:org/projects/:project/tasks/:task", |_req, params| {
        let org = params.get("org").unwrap();
        let project = params.get("project").unwrap();
        let task = params.get("task").unwrap();
        HttpResponse::ok(&format!("{}/{}/{}", org, project, task))
    });

    let req = HttpRequest {
        method: "GET",
        path: "/orgs/deepmind/projects/antigravity/tasks/42",
    };
    let resp = router.dispatch(&req);
    assert_eq!(resp, HttpResponse::ok("deepmind/antigravity/42"));
}

fn main() {
    let mut router = Router::new();
    router.get("/status", |_req, _p| HttpResponse::ok("healthy"));

    let req_post = HttpRequest { method: "POST", path: "/status" };
    match router.dispatch_strict(&req_post) {
        DispatchResult::MethodNotAllowed(methods) => assert_eq!(methods, vec!["GET"]),
        _ => panic!("Expected 405 Method Not Allowed"),
    }

    test_multiple_params();
    println!("All routing engine exercises passed!");
