## Concept

In this capstone lesson for Phase 4, we integrate all our networking, parsing, routing, and concurrency components into a **complete, asynchronous HTTP/1.1 Web Server** powered by **Tokio**.

```
Incoming TCP Connections on 0.0.0.0:8080
                 │
                 ▼
     [ tokio::net::TcpListener ]
                 │
                 ├──► tokio::spawn(Task 1) ──► Read Buffer ──► Zero-Copy Parse ──► Router ──► Response
                 ├──► tokio::spawn(Task 2) ──► Read Buffer ──► Zero-Copy Parse ──► Router ──► Response
                 └──► tokio::spawn(Task N) ... (100,000+ Concurrent Green Tasks)
```

---

### 1. The Core Architecture

1. **Async Listener Loop**: Binds to `tokio::net::TcpListener` and awaits connections.
2. **Task-per-Connection**: Each incoming socket is handed off to `tokio::spawn`, running cooperatively without thread blocking.
3. **Incremental Buffering**: Reads bytes asynchronously until the complete HTTP header (`\r\n\r\n`) and body have arrived.
4. **Router & Middleware Dispatch**: Matches routes, validates tokens, and executes business handlers.
5. **Graceful Shutdown**: Listens for `tokio::signal::ctrl_c()` to shut down without dropping active connections.

---

## Why it matters

- **Production Performance**: This architecture matches the execution model of industry web engines (e.g. NGINX, Hyper, Actix), delivering sub-millisecond response latencies and supporting 100,000+ concurrent requests.
- **Synthesizing Rust Concepts**: It applies the full spectrum of Rust: lifetimes, ownership, trait objects, generics, error propagation, atomics, and async runtimes.

---

## Analogy

Think of an **Air Traffic Control Tower**:
- The `TcpListener` is the radar watching the sky.
- Incoming planes (requests) are handed off to individual automated approach paths (`Tokio green tasks`).
- Each plane is guided through customs (Middleware), assigned to its specific landing gate (Router), and dispatched back to the runway (Response) with zero mid-air collisions.

## Code Example

Add `tokio` to `Cargo.toml`:
```toml
[dependencies]
tokio = { version = "1", features = ["full"] }
```

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::collections::HashMap;
use std::sync::Arc;
use std::time::Duration;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::{TcpListener, TcpStream};

// ---------------------------------------------------------------------------
// 1. HTTP Models
// ---------------------------------------------------------------------------
#[derive(Debug)]
pub struct HttpRequest<'a> {
    pub method: &'a str,
    pub path: &'a str,
    pub headers: Vec<(&'a str, &'a str)>,
    pub body: &'a [u8],
}

impl<'a> HttpRequest<'a> {
    pub fn parse(buffer: &'a [u8]) -> Option<Self> {
        let header_end = buffer.windows(4).position(|w| w == b"\r\n\r\n")?;
        let header_str = std::str::from_utf8(&buffer[..header_end]).ok()?;
        let body_bytes = &buffer[header_end + 4..];

        let mut lines = header_str.split("\r\n");
        let request_line = lines.next()?;
        let mut parts = request_line.split_whitespace();

        let method = parts.next()?;
        let path = parts.next()?;

        let mut headers = Vec::new();
        let mut content_length = 0;

        for line in lines {
            if let Some((k, v)) = line.split_once(':') {
                let k_trim = k.trim();
                let v_trim = v.trim();
                if k_trim.eq_ignore_ascii_case("content-length") {
                    content_length = v_trim.parse::<usize>().unwrap_or(0);
                }
                headers.push((k_trim, v_trim));
            }
        }

        if body_bytes.len() < content_length {
            return None; // Wait for rest of payload
        }

        Some(HttpRequest {
            method,
            path,
            headers,
            body: &body_bytes[..content_length],
        })
    }
}

pub struct HttpResponse {
    pub status: u16,
    pub status_text: &'static str,
    pub content_type: &'static str,
    pub body: Vec<u8>,
}

impl HttpResponse {
    pub fn ok_json(payload: &str) -> Self {
        HttpResponse {
            status: 200,
            status_text: "OK",
            content_type: "application/json",
            body: payload.as_bytes().to_vec(),
        }
    }

    pub fn ok_text(text: &str) -> Self {
        HttpResponse {
            status: 200,
            status_text: "OK",
            content_type: "text/plain; charset=utf-8",
            body: text.as_bytes().to_vec(),
        }
    }

    pub fn not_found() -> Self {
        HttpResponse {
            status: 404,
            status_text: "Not Found",
            content_type: "text/plain",
            body: b"404 Endpoint Not Found".to_vec(),
        }
    }

    pub fn to_bytes(&self) -> Vec<u8> {
        let header = format!(
            "HTTP/1.1 {} {}\r\nContent-Type: {}\r\nContent-Length: {}\r\nConnection: close\r\nServer: RustAsync/1.0\r\n\r\n",
            self.status,
            self.status_text,
            self.content_type,
            self.body.len()
        );

        let mut bytes = header.into_bytes();
        bytes.extend_from_slice(&self.body);
        bytes
    }
}

// ---------------------------------------------------------------------------
// 2. Async Router
// ---------------------------------------------------------------------------
pub type PathParams = HashMap<String, String>;
pub type RouteHandler = Arc<dyn Fn(&HttpRequest, &PathParams) -> HttpResponse + Send + Sync>;

pub struct AsyncRouter {
    routes: Vec<(String, String, RouteHandler)>,
}

impl AsyncRouter {
    pub fn new() -> Self {
        AsyncRouter { routes: Vec::new() }
    }

    pub fn get<F>(&mut self, path: &str, handler: F)
    where
        F: Fn(&HttpRequest, &PathParams) -> HttpResponse + Send + Sync + 'static,
    {
        self.routes.push(("GET".to_string(), path.to_string(), Arc::new(handler)));
    }

    pub fn post<F>(&mut self, path: &str, handler: F)
    where
        F: Fn(&HttpRequest, &PathParams) -> HttpResponse + Send + Sync + 'static,
    {
        self.routes.push(("POST".to_string(), path.to_string(), Arc::new(handler)));
    }

    pub fn dispatch(&self, req: &HttpRequest) -> HttpResponse {
        for (method, pattern, handler) in &self.routes {
            if method == req.method && pattern == req.path {
                let params = HashMap::new();
                return handler(req, &params);
            }
        }
        HttpResponse::not_found()
    }
}

// ---------------------------------------------------------------------------
// 3. Client Connection Worker
// ---------------------------------------------------------------------------
async fn handle_connection(mut socket: TcpStream, router: Arc<AsyncRouter>) {
    let mut buffer = vec![0u8; 4096];
    let mut total_read = 0;

    // Read loop
    loop {
        match socket.read(&mut buffer[total_read..]).await {
            Ok(0) => return, // EOF
            Ok(bytes) => {
                total_read += bytes;
                if let Some(req) = HttpRequest::parse(&buffer[..total_read]) {
                    println!("[Request] {} {}", req.method, req.path);
                    let response = router.dispatch(&req);
                    let resp_bytes = response.to_bytes();
                    let _ = socket.write_all(&resp_bytes).await;
                    let _ = socket.flush().await;
                    return;
                }
                if total_read >= buffer.len() {
                    buffer.resize(buffer.len() * 2, 0);
                }
            }
            Err(_) => return,
        }
    }
}

// ---------------------------------------------------------------------------
// 4. Main Server Loop with Graceful Shutdown
// ---------------------------------------------------------------------------
#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut router = AsyncRouter::new();

    // Register API endpoints
    router.get("/health", |_req, _params| {
        HttpResponse::ok_json(r#"{"status":"healthy","uptime_sec":120}"#)
    });

    router.get("/api/v1/metrics", |_req, _params| {
        HttpResponse::ok_text("requests_total 42510\nlatency_p99_ms 1.4\n")
    });

    router.post("/api/v1/echo", |req, _params| {
        let body_str = String::from_utf8_lossy(req.body);
        HttpResponse::ok_json(&format!(r#"{{"echo":"{}"}}"#, body_str))
    });

    let router = Arc::new(router);
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("🚀 Async HTTP Server running on http://127.0.0.1:8080");

    // Spawn listener loop in background task
    let server_router = Arc::clone(&router);
    tokio::spawn(async move {
        loop {
            if let Ok((socket, _)) = listener.accept().await {
                let r = Arc::clone(&server_router);
                tokio::spawn(async move {
                    handle_connection(socket, r).await;
                });
            }
        }
    });

    // Run client test query against our async server
    tokio::time::sleep(Duration::from_millis(50)).await;
    let mut client = TcpStream::connect("127.0.0.1:8080").await?;
    client.write_all(b"GET /health HTTP/1.1\r\nHost: localhost\r\n\r\n").await?;

    let mut resp_buf = vec![0u8; 1024];
    let n = client.read(&mut resp_buf).await?;
    let resp_str = String::from_utf8_lossy(&resp_buf[..n]);
    println!("\n--- Received Server Response ---");
    println!("{}", resp_str);
    assert!(resp_str.contains("200 OK"));
    assert!(resp_str.contains(r#"{"status":"healthy""#));

    println!("Async HTTP Server successfully tested and verified!");
    Ok(())
}
```

## Common Mistakes

### 1. Spawning Blocking I/O Inside Async Handlers
Calling `std::thread::sleep` or synchronous database drivers inside an `async fn`. This blocks the underlying Tokio worker thread, preventing thousands of other tasks on that thread from running. Always use `tokio::time::sleep` and async drivers.

---

### 2. Missing Max Payload Bounds (Memory Exhaustion)
Resizing the read buffer indefinitely if a malicious client sends an unending stream of bytes without CRLF. Always enforce a hard ceiling (e.g., max 10MB) and return `413 Payload Too Large`.

---

### 3. Dropping Sockets Before `flush().await`
Dropping the `TcpStream` before `socket.flush().await` completes can cause the OS kernel to send a `TCP RST` packet to the client, dropping the response bytes in transit.

## Solutions

### Solution to Exercise 1
```rust
const MAX_PAYLOAD_BYTES: usize = 1024 * 1024; // 1 MB limit

async fn handle_connection_with_limit(mut socket: TcpStream, router: Arc<AsyncRouter>) {
    let mut buffer = vec![0u8; 4096];
    let mut total_read = 0;

    loop {
        match socket.read(&mut buffer[total_read..]).await {
            Ok(0) => return,
            Ok(bytes) => {
                total_read += bytes;
                if total_read > MAX_PAYLOAD_BYTES {
                    let resp = b"HTTP/1.1 413 Payload Too Large\r\nConnection: close\r\n\r\n";
                    let _ = socket.write_all(resp).await;
                    return;
                }
                if let Some(req) = HttpRequest::parse(&buffer[..total_read]) {
                    let response = router.dispatch(&req);
                    let _ = socket.write_all(&response.to_bytes()).await;
                    let _ = socket.flush().await;
                    return;
                }
                if total_read >= buffer.len() {
                    buffer.resize(buffer.len() * 2, 0);
                }
            }
            Err(_) => return,
        }
    }
}
```

### Solution to Exercise 2
```rust
async fn run_server_with_shutdown(listener: TcpListener, router: Arc<AsyncRouter>) {
    println!("Server running. Press Ctrl+C to shut down.");

    loop {
        tokio::select! {
            accept_res = listener.accept() => {
                if let Ok((socket, _)) = accept_res {
                    let r = Arc::clone(&router);
                    tokio::spawn(async move {
                        handle_connection(socket, r).await;
                    });
                }
            }
            _ = tokio::signal::ctrl_c() => {
                println!("\n[Shutdown] Received Ctrl+C. Server shutting down cleanly.");
                break;
            }
        }
    }
}
```

### Solution to Exercise 3
```rust
#[tokio::test]
async fn test_non_blocking_delay_endpoint() {
    let mut router = AsyncRouter::new();
    router.get("/delay", |_req, _p| {
        HttpResponse::ok_text("Delayed Response OK")
    });
    router.get("/fast", |_req, _p| {
        HttpResponse::ok_text("Fast")
    });

    let router = Arc::new(router);
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let addr = listener.local_addr().unwrap();

    let r = Arc::clone(&router);
    tokio::spawn(async move {
        while let Ok((socket, _)) = listener.accept().await {
            let r_clone = Arc::clone(&r);
            tokio::spawn(handle_connection(socket, r_clone));
        }
    });

    // Make concurrent request to /fast
    let mut client = TcpStream::connect(addr).await.unwrap();
    client.write_all(b"GET /fast HTTP/1.1\r\n\r\n").await.unwrap();
    let mut buf = vec![0u8; 512];
    let n = client.read(&mut buf).await.unwrap();
    assert!(String::from_utf8_lossy(&buf[..n]).contains("Fast"));
}
```
