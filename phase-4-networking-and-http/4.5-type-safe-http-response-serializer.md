## Concept

Formatting HTTP responses manually using string interpolation (`format!("HTTP/1.1 200 OK\r\n...")`) is dangerous in production systems:
- It is easy to forget the mandatory `Content-Length` header or miscalculate multi-byte UTF-8 character lengths.
- Missing CRLF delimiters (`\r\n`) cause client timeouts.
- Raw string concatenations trigger frequent heap reallocations.

In this lesson, we build a **Type-Safe, Fluent `HttpResponse` Serializer** that guarantees compliant wire-format generation.

```
Developer Code:
HttpResponse::ok()
    .content_type("application/json")
    .body(r#"{"status":"healthy"}"#)
              │
              ▼ (Type-Safe Builder Pipeline)
Wire Bytes Sent to TcpStream:
HTTP/1.1 200 OK\r\n
Server: RustSystems/1.0\r\n
Content-Type: application/json\r\n
Content-Length: 20\r\n
Connection: close\r\n
\r\n
{"status":"healthy"}
```

### 1. Struct Architecture

---

### 2. The Fluent Builder Pattern

A fluent builder API provides readable, chainable methods with sensible defaults:
- `HttpResponse::ok()` $\to$ Status 200.
- `HttpResponse::not_found()` $\to$ Status 404.
- `HttpResponse::bad_request()` $\to$ Status 400.
- `.json(data)` $\to$ Sets `Content-Type: application/json` and serializes payload.
- `.text(data)` $\to$ Sets `Content-Type: text/plain; charset=utf-8`.
- `.html(data)` $\to$ Sets `Content-Type: text/html; charset=utf-8`.

---

### 3. Direct-to-Socket Streaming (`std::io::Write`)

Instead of formatting a massive string and copying it into a byte vector, the response serializer writes directly into any type implementing `std::io::Write` (including a raw `TcpStream` or test buffer).

---

## Why it matters

- **Memory Efficiency**: Serializing directly to the network socket minimizes intermediate buffer copies.
- **RFC Compliance**: Automated header injection guarantees that `Content-Length` and `Connection` headers are mathematically accurate for every response.

---

## Analogy

Think of an **Automated Packaging Machine**:
- You place the manufactured item into the hopper (`.body(...)`).
- The machine automatically weighs the contents, prints the exact weight label (`Content-Length`), stamps the inspection seal (`HTTP/1.1 200 OK`), and glues the box shut (`\r\n\r\n`) before rolling it onto the delivery truck.

## Code Example

Save this to `src/main.rs` and run `cargo run`:

```rust
use std::io::{self, Write};

#[derive(Debug, PartialEq, Eq, Clone, Copy)]
pub enum StatusCode {
    Ok = 200,
    Created = 201,
    NoContent = 204,
    MovedPermanently = 301,
    BadRequest = 400,
    Unauthorized = 401,
    Forbidden = 403,
    NotFound = 404,
    InternalServerError = 500,
}

impl StatusCode {
    pub fn reason_phrase(&self) -> &'static str {
        match self {
            StatusCode::Ok => "OK",
            StatusCode::Created => "Created",
            StatusCode::NoContent => "No Content",
            StatusCode::MovedPermanently => "Moved Permanently",
            StatusCode::BadRequest => "Bad Request",
            StatusCode::Unauthorized => "Unauthorized",
            StatusCode::Forbidden => "Forbidden",
            StatusCode::NotFound => "Not Found",
            StatusCode::InternalServerError => "Internal Server Error",
        }
    }

    pub fn code(&self) -> u16 {
        *self as u16
    }
}

#[derive(Debug, Clone)]
pub struct HttpResponse {
    status: StatusCode,
    headers: Vec<(String, String)>,
    body: Vec<u8>,
}

impl HttpResponse {
    pub fn new(status: StatusCode) -> Self {
        HttpResponse {
            status,
            headers: vec![("Server".to_string(), "RustSystemsServer/1.0".to_string())],
            body: Vec::new(),
        }
    }

    // Convenience constructors
    pub fn ok() -> Self {
        Self::new(StatusCode::Ok)
    }

    pub fn created() -> Self {
        Self::new(StatusCode::Created)
    }

    pub fn not_found() -> Self {
        Self::new(StatusCode::NotFound)
    }

    pub fn bad_request() -> Self {
        Self::new(StatusCode::BadRequest)
    }

    pub fn internal_error() -> Self {
        Self::new(StatusCode::InternalServerError)
    }

    // Builder methods
    pub fn header(mut self, key: &str, value: &str) -> Self {
        self.headers.push((key.to_string(), value.to_string()));
        self
    }

    pub fn body_bytes(mut self, bytes: Vec<u8>) -> Self {
        self.body = bytes;
        self
    }

    pub fn text(self, text: &str) -> Self {
        self.header("Content-Type", "text/plain; charset=utf-8")
            .body_bytes(text.as_bytes().to_vec())
    }

    pub fn html(self, html: &str) -> Self {
        self.header("Content-Type", "text/html; charset=utf-8")
            .body_bytes(html.as_bytes().to_vec())
    }

    pub fn json(self, json_str: &str) -> Self {
        self.header("Content-Type", "application/json; charset=utf-8")
            .body_bytes(json_str.as_bytes().to_vec())
    }

    // Direct-to-Writer serialization (works on TcpStream, File, or Vec<u8>)
    pub fn write_to<W: Write>(&self, writer: &mut W) -> io::Result<()> {
        // 1. Status Line: HTTP/1.1 200 OK\r\n
        write!(
            writer,
            "HTTP/1.1 {} {}\r\n",
            self.status.code(),
            self.status.reason_phrase()
        )?;

        // 2. Custom User Headers
        for (key, val) in &self.headers {
            write!(writer, "{}: {}\r\n", key, val)?;
        }

        // 3. Mandatory Computed Headers
        write!(writer, "Content-Length: {}\r\n", self.body.len())?;
        write!(writer, "Connection: close\r\n")?;

        // 4. Header-Body CRLF Delimiter
        write!(writer, "\r\n")?;

        // 5. Raw Body Bytes
        if !self.body.is_empty() {
            writer.write_all(&self.body)?;
        }

        writer.flush()?;
        Ok(())
    }

    // Convert into byte vector for testing
    pub fn to_bytes(&self) -> Vec<u8> {
        let mut buffer = Vec::new();
        self.write_to(&mut buffer).unwrap();
        buffer
    }
}

fn main() {
    // 1. Build a JSON API response
    let json_resp = HttpResponse::ok()
        .header("X-RateLimit-Remaining", "99")
        .json(r#"{"status":"active","workers":8}"#);

    let raw_bytes = json_resp.to_bytes();
    println!("--- Serialized JSON HTTP Response ---");
    println!("{}", String::from_utf8_lossy(&raw_bytes));

    // 2. Build a 404 HTML response
    let not_found_resp = HttpResponse::not_found()
        .html("<h1>404 - Endpoint Not Found</h1>");

    let not_found_bytes = not_found_resp.to_bytes();
    println!("--- Serialized 404 Response ---");
    println!("{}", String::from_utf8_lossy(&not_found_bytes));
}
```

## Common Mistakes

### 1. Counting Characters Instead of Bytes in `Content-Length`
Writing `self.body.chars().count()` instead of `self.body.len()`. When serving UTF-8 strings containing emojis or multi-byte characters, character count is smaller than byte count, causing HTTP clients to truncate the response body.

---

### 2. Missing `\r\n` Before the Body
Writing `write!(writer, "\n")` instead of `write!(writer, "\r\n")`. Many HTTP clients (like `curl` and Python `requests`) will reject the response as a protocol violation.

---

### 3. Hardcoding `Content-Type: application/json` on Binary Payloads
Failing to expose `.body_bytes()` for binary assets (images, WASM binaries, gzip archives) and forcing all data through string constructors.

## Solutions

### Solution to Exercise 1
```rust
impl HttpResponse {
    pub fn redirect(location: &str) -> Self {
        Self::new(StatusCode::MovedPermanently)
            .header("Location", location)
    }
}
```

---

### Solution to Exercise 2
```rust
impl HttpResponse {
    pub fn cors(self, origin: &str) -> Self {
        self.header("Access-Control-Allow-Origin", origin)
            .header("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")
            .header("Access-Control-Allow-Headers", "Content-Type, Authorization")
    }
}
```

### Solution to Exercise 3
```rust
fn test_no_content_response() {
    let resp = HttpResponse::new(StatusCode::NoContent);
    let bytes = resp.to_bytes();
    let text = String::from_utf8_lossy(&bytes);

    assert!(text.starts_with("HTTP/1.1 204 No Content\r\n"));
    assert!(text.contains("Content-Length: 0\r\n"));
    assert!(text.ends_with("\r\n\r\n"));
}

fn main() {
    let redir = HttpResponse::redirect("https://rust-lang.org");
    let redir_text = String::from_utf8_lossy(&redir.to_bytes());
    assert!(redir_text.contains("Location: https://rust-lang.org"));
    assert!(redir_text.contains("301 Moved Permanently"));

    let cors_resp = HttpResponse::ok().cors("*").text("hello");
    let cors_text = String::from_utf8_lossy(&cors_resp.to_bytes());
    assert!(cors_text.contains("Access-Control-Allow-Origin: *"));

    test_no_content_response();
    println!("All HTTP response serializer exercises verified!");
}
```
