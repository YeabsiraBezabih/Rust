## Concept

In professional backend engineering, an API is only as good as its documentation. Historically, writing API docs was a manual, error-prone chore: developers wrote API specs in YAML or JSON, resulting in severe **documentation drift** when code changed but documentation was forgotten.

In Rust, the **`utoipa`** crate provides compile-time, code-first OpenAPI 3.0 specification generation using procedural derive macros.

```
                  ┌──────────────────────────────────────────────┐
                  │          Rust Source Code + Macros           │
                  │   #[utoipa::path], #[derive(ToSchema)]       │
                  └──────────────────────┬───────────────────────┘
                                         │ Compile-Time Reflection
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │            OpenAPI 3.0 JSON Spec             │
                  │           ApiDoc::openapi().to_json()        │
                  └──────────────────────┬───────────────────────┘
                                         │
                    ┌────────────────────┴────────────────────┐
                    ▼                                         ▼
       ┌─────────────────────────┐               ┌─────────────────────────┐
       │   Interactive Swagger   │               │ Client Code Generation  │
       │   UI at `/swagger-ui`   │               │ (TypeScript / Go / Dart)│
       └─────────────────────────┘               └─────────────────────────┘
```

---

### Core Components of Utoipa

#### 1. `#[derive(ToSchema)]` for DTOs
Deriving `ToSchema` on data structs and enums automatically exposes their JSON Schema definitions to OpenAPI:

```rust
use serde::{Deserialize, Serialize};
use utoipa::ToSchema;

#[derive(Serialize, Deserialize, ToSchema)]
pub struct UserDto {
    #[schema(example = "usr_948102")]
    pub id: String,
    #[schema(example = "satoshi@bitcoin.org")]
    pub email: String,
    #[schema(example = "active")]
    pub status: UserStatus,
}

#[derive(Serialize, Deserialize, ToSchema)]
pub enum UserStatus {
    Active,
    Suspended,
    PendingVerification,
}
```

#### 2. `#[utoipa::path(...)]` for Endpoint Documentation
Annotating Axum handler functions with the `#[utoipa::path]` macro defines HTTP methods, route paths, query parameters, request bodies, response codes, and security requirements:

```rust
#[utoipa::path(
    post,
    path = "/api/v1/users",
    request_body = CreateUserRequest,
    responses(
        (status = 201, description = "User created successfully", body = UserDto),
        (status = 400, description = "Invalid payload or validation failed", body = ErrorResponse),
        (status = 409, description = "User with email already exists", body = ErrorResponse)
    ),
    tag = "Users",
    security(
        ("bearer_auth" = [])
    )
)]
pub async fn create_user(
    State(state): State<Arc<AppState>>,
    Json(payload): Json<CreateUserRequest>,
) -> Result<(StatusCode, Json<UserDto>), (StatusCode, Json<ErrorResponse>)> {
    // Handler logic...
}
```

#### 3. `#[derive(OpenApi)]` Root Aggregator
Aggregates all paths, schema components, tags, and security schemes into a single root spec:

```rust
use utoipa::OpenApi;

#[derive(OpenApi)]
#[openapi(
    paths(
        create_user,
        get_user_by_id,
        list_users
    ),
    components(
        schemas(UserDto, UserStatus, CreateUserRequest, ErrorResponse)
    ),
    tags(
        (name = "Users", description = "User management and provisioning endpoints")
    ),
    info(
        title = "Enterprise Payment Engine API",
        version = "1.0.0",
        description = "High-performance financial ledger and transaction processing API."
    )
)]
pub struct ApiDoc;
```

#### 4. Serving Swagger UI in Axum
Using `utoipa-swagger-ui`, you can attach an interactive API explorer with zero external static assets:

```rust
use utoipa_swagger_ui::SwaggerUi;

let app = Router::new()
    .merge(SwaggerUi::new("/swagger-ui").url("/api-docs/openapi.json", ApiDoc::openapi()))
    .route("/api/v1/users", post(create_user));
```

## Why It Matters in Systems Programming

1. **Zero Documentation Drift**: The OpenAPI specification is derived directly from the exact types and functions compiled into the binary. If a field name or type changes in Rust, the documentation is automatically updated at compile time.
2. **Automated SDK Generation**: Frontend and mobile teams can automatically generate TypeScript, Dart, Swift, or Go client libraries from your `/api-docs/openapi.json` using tools like `openapi-generator` or `orval`.
3. **Automated Security & Auth Contracts**: Clearly exposes JWT Bearer schemes, OAuth2 scopes, and API key header requirements directly inside Swagger UI, allowing QA engineers and frontend developers to test secured endpoints interactively with "Authorize" modals.

## Complete, Compilable Code Example

Below is a complete, self-contained Axum service featuring declarative OpenAPI documentation, DTO schemas, custom error responses, and Swagger UI integration.

```rust
use axum::{
    extract::{Path, State},
    http::StatusCode,
    response::IntoResponse,
    routing::{get, post},
    Json, Router,
};
use serde::{Deserialize, Serialize};
use std::collections::HashMap;
use std::sync::{Arc, RwLock};
use utoipa::{OpenApi, ToSchema};
use utoipa_swagger_ui::SwaggerUi;

// ============================================================================
// 1. Data Transfer Objects (DTOs) with OpenAPI Schemas
// ============================================================================

#[derive(Debug, Clone, Serialize, Deserialize, ToSchema)]
pub struct Product {
    #[schema(example = 101)]
    pub id: u64,
    #[schema(example = "Ultra-Fast NVMe SSD 2TB")]
    pub name: String,
    #[schema(example = 179.99)]
    pub price: f64,
    #[schema(example = 45)]
    pub stock: u32,
    #[schema(example = "Hardware")]
    pub category: ProductCategory,
}

#[derive(Debug, Clone, Serialize, Deserialize, ToSchema)]
pub enum ProductCategory {
    Hardware,
    Software,
    Peripherals,
    Accessories,
}

#[derive(Debug, Deserialize, ToSchema)]
pub struct CreateProductRequest {
    #[schema(example = "Mechanical Gaming Keyboard RGB")]
    pub name: String,
    #[schema(example = 89.50)]
    pub price: f64,
    #[schema(example = 120)]
    pub stock: u32,
    pub category: ProductCategory,
}

#[derive(Debug, Serialize, ToSchema)]
pub struct ErrorResponse {
    #[schema(example = "ERR_PRODUCT_NOT_FOUND")]
    pub error_code: String,
    #[schema(example = "No product exists with ID 999")]
    pub message: String,
}

// ============================================================================
// 2. Shared Application State
// ============================================================================

pub struct AppState {
    pub products: RwLock<HashMap<u64, Product>>,
    pub next_id: RwLock<u64>,
}

// ============================================================================
// 3. Documented Route Handlers (#[utoipa::path])
// ============================================================================

/// List all products in the catalog
#[utoipa::path(
    get,
    path = "/api/v1/products",
    responses(
        (status = 200, description = "List of all products in inventory", body = Vec<Product>)
    ),
    tag = "Products"
)]
async fn list_products(State(state): State<Arc<AppState>>) -> Json<Vec<Product>> {
    let map = state.products.read().unwrap();
    let list: Vec<Product> = map.values().cloned().collect();
    Json(list)
}

/// Retrieve a product by unique ID
#[utoipa::path(
    get,
    path = "/api/v1/products/{id}",
    params(
        ("id" = u64, Path, description = "Unique numeric identifier of the product")
    ),
    responses(
        (status = 200, description = "Product details retrieved successfully", body = Product),
        (status = 404, description = "Product not found", body = ErrorResponse)
    ),
    tag = "Products"
)]
async fn get_product(
    State(state): State<Arc<AppState>>,
    Path(id): Path<u64>,
) -> Result<Json<Product>, (StatusCode, Json<ErrorResponse>)> {
    let map = state.products.read().unwrap();
    match map.get(&id) {
        Some(product) => Ok(Json(product.clone())),
        None => Err((
            StatusCode::NOT_FOUND,
            Json(ErrorResponse {
                error_code: "ERR_PRODUCT_NOT_FOUND".to_string(),
                message: format!("Product with ID {} not found", id),
            }),
        )),
    }
}

/// Create and register a new product
#[utoipa::path(
    post,
    path = "/api/v1/products",
    request_body = CreateProductRequest,
    responses(
        (status = 201, description = "Product successfully created", body = Product),
        (status = 400, description = "Invalid product attributes", body = ErrorResponse)
    ),
    tag = "Products"
)]
async fn create_product(
    State(state): State<Arc<AppState>>,
    Json(payload): Json<CreateProductRequest>,
) -> Result<(StatusCode, Json<Product>), (StatusCode, Json<ErrorResponse>)> {
    if payload.price <= 0.0 {
        return Err((
            StatusCode::BAD_REQUEST,
            Json(ErrorResponse {
                error_code: "ERR_INVALID_PRICE".to_string(),
                message: "Product price must be greater than zero".to_string(),
            }),
        ));
    }

    let mut next_id_lock = state.next_id.write().unwrap();
    let id = *next_id_lock;
    *next_id_lock += 1;

    let product = Product {
        id,
        name: payload.name,
        price: payload.price,
        stock: payload.stock,
        category: payload.category,
    };

    let mut map = state.products.write().unwrap();
    map.insert(id, product.clone());

    Ok((StatusCode::CREATED, Json(product)))
}

// ============================================================================
// 4. OpenAPI Specification Root Definition
// ============================================================================

#[derive(OpenApi)]
#[openapi(
    paths(
        list_products,
        get_product,
        create_product
    ),
    components(
        schemas(Product, ProductCategory, CreateProductRequest, ErrorResponse)
    ),
    tags(
        (name = "Products", description = "Product catalog & inventory management API")
    ),
    info(
        title = "Cloud E-Commerce Inventory API",
        version = "1.0.0",
        description = "High-performance Rust Axum API with live OpenAPI 3.0 specification."
    )
)]
pub struct ApiDoc;

// ============================================================================
// 5. Main Server Setup & Router Assembly
// ============================================================================

#[tokio::main]
async fn main() {
    let mut initial_products = HashMap::new();
    initial_products.insert(
        1,
        Product {
            id: 1,
            name: "Mechanical Keyboard".to_string(),
            price: 129.99,
            stock: 30,
            category: ProductCategory::Peripherals,
        },
    );

    let state = Arc::new(AppState {
        products: RwLock::new(initial_products),
        next_id: RwLock::new(2),
    });

    // Build Axum Router and merge Swagger UI endpoint
    let app = Router::new()
        .merge(SwaggerUi::new("/swagger-ui").url("/api-docs/openapi.json", ApiDoc::openapi()))
        .route("/api/v1/products", get(list_products).post(create_product))
        .route("/api/v1/products/:id", get(get_product))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .expect("Failed to bind port 3000");

    println!("============================================================");
    println!("API Server running at http://127.0.0.1:3000");
    println!("Interactive Swagger UI: http://127.0.0.1:3000/swagger-ui");
    println!("Raw OpenAPI JSON Spec:  http://127.0.0.1:3000/api-docs/openapi.json");
    println!("============================================================");

    // axum::serve(listener, app).await.unwrap();
}
```

## Common Pitfalls & Compiler Errors

### 1. Missing `components(schemas(...))` in `#[derive(OpenApi)]`
If a DTO is referenced in a handler's `responses(...)` or `request_body`, but forgotten in `components(schemas(...))` in the `ApiDoc` struct, Swagger UI will fail to render the schema or display an unresolved `$ref` error.

**Fix**: Ensure every referenced DTO type is listed in `components(schemas(TypeA, TypeB, ...))`.

### 2. Mismatched Path Parameters in `#[utoipa::path]` vs Axum Route
Axum uses `:id` in router definitions (`/api/v1/products/:id`), but OpenAPI 3.0 requires `{id}` in the path attribute (`path = "/api/v1/products/{id}"`).
If you write `:id` inside `#[utoipa::path]`, OpenAPI schema validation tools will flag invalid path syntax.

### 3. Missing `ToSchema` on Nested Types
If a struct `Order` contains a field `items: Vec<OrderItem>`, `OrderItem` must also implement `ToSchema`. If `OrderItem` does not derive `ToSchema`, compilation will fail with:
```
error[E0277]: the trait `utoipa::ToSchema` is not implemented for `OrderItem`
```

## Complete Solutions to Exercises

### Solution 1: Documented DELETE Endpoint

```rust
/// Delete a product from inventory by ID
#[utoipa::path(
    delete,
    path = "/api/v1/products/{id}",
    params(
        ("id" = u64, Path, description = "Unique numeric identifier of the product to delete")
    ),
    responses(
        (status = 204, description = "Product successfully deleted"),
        (status = 404, description = "Product not found", body = ErrorResponse)
    ),
    tag = "Products"
)]
async fn delete_product(
    State(state): State<Arc<AppState>>,
    Path(id): Path<u64>,
) -> Result<StatusCode, (StatusCode, Json<ErrorResponse>)> {
    let mut map = state.products.write().unwrap();
    if map.remove(&id).is_some() {
        Ok(StatusCode::NO_CONTENT)
    } else {
        Err((
            StatusCode::NOT_FOUND,
            Json(ErrorResponse {
                error_code: "ERR_PRODUCT_NOT_FOUND".to_string(),
                message: format!("Product with ID {} not found", id),
            }),
        ))
    }
}
```

### Solution 2: Adding Bearer Security Scheme to OpenAPI

```rust
use utoipa::openapi::security::{HttpAuthScheme, HttpBuilder, SecurityScheme};
use utoipa::Modify;

struct SecurityAddon;

impl Modify for SecurityAddon {
    fn modify(&self, openapi: &mut utoipa::openapi::OpenApi) {
        if let Some(components) = openapi.components.as_mut() {
            components.add_security_scheme(
                "bearer_auth",
                SecurityScheme::Http(
                    HttpBuilder::new()
                        .scheme(HttpAuthScheme::Bearer)
                        .bearer_format("JWT")
                        .build(),
                ),
            );
        }
    }
}

#[derive(OpenApi)]
#[openapi(
    paths(list_products, get_product, create_product, delete_product),
    components(schemas(Product, ProductCategory, CreateProductRequest, ErrorResponse)),
    modifiers(&SecurityAddon),
    tags((name = "Products", description = "Product management API"))
)]
pub struct ApiDoc;
```
