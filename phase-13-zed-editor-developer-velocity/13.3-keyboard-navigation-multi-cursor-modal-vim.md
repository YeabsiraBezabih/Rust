## Concept

In professional systems programming, **editing speed is bounded by navigation and refactoring friction, not typing speed**. Reaching for the mouse disrupts cognitive focus and slows down iterative debugging loops.

Zed provides first-class, zero-latency **Vim Modal Editing** alongside modern **Multi-Cursor Manipulation** and **Semantic Symbol Navigation**.

### 1. Enabling Vim Mode in Zed

Add `"vim_mode": true` to your `~/.config/zed/settings.json`:

```json
{
  "vim_mode": true,
  "vim": {
    "use_system_clipboard": "always",
    "use_multiline_find": true
  }
}
```

### 2. High-Frequency Vim Text Objects for Rust Code

Text objects allow you to target semantic code boundaries without manually highlighting text:

| Command | Action in Rust Code | Example |
| :--- | :--- | :--- |
| `ciw` | **Change Inside Word** | Rename variable or function name instantly. |
| `ci"` | **Change Inside Quotes** | Replace string literals (e.g. `"SELECT * FROM users"`). |
| `ci(` or `cib`| **Change Inside Parentheses** | Replace all arguments inside a function call. |
| `da{` or `daB`| **Delete Around Braces** | Delete an entire `impl` block, struct definition, or `match` branch. |
| `yi[` | **Yank Inside Brackets** | Copy array elements or slice definitions. |
| `vip` | **Visual Inside Paragraph**| Select an entire contiguous code block for formatting or moving. |

---

### 3. Multi-Cursor & Multi-Buffer Refactoring

Zed allows you to combine Vim motions with Multi-Cursor editing:

1. **Select Next Occurrence**: `ctrl-d` (Linux/Windows) or `cmd-d` (macOS) highlights the word under cursor; pressing it repeatedly spawns new cursors at each subsequent match.
2. **Select All Occurrences**: `ctrl-shift-l` or `cmd-shift-l` spawns cursors on every match across the entire file or active multi-buffer excerpt.
3. **Columnar / Box Selection**: `ctrl-alt-up` / `ctrl-alt-down` places vertical cursors across multiple lines for editing struct field definitions in bulk.

## Why It Matters in Systems Programming

1. **Zero-Latency Trait Refactoring**: When adding a method to a trait, use `ctrl-t` to jump to the trait definition, copy the signature, use `g r` (find all references) to open all implementors in a **Multi-Buffer**, and paste/implement the method across all structs simultaneously.
2. **Speed in Data Struct Transformation**: Converting JSON models or SQL schemas into Rust structs takes seconds using columnar multi-cursors (`ctrl-alt-down`) and Vim text replacement (`ciw`).
3. **Ergonomic Longevity**: Minimizing mouse reaching prevents repetitive strain injury (RSI) during 10+ hour deep programming sessions.

## Complete, Compilable Code Example

The following code is a prime example of a data model and state machine that can be refactored with Vim text objects and multi-cursor workflows:

```rust
use std::collections::HashMap;

/// State Machine for a High-Throughput Network Packet Router
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PacketState {
    IngressReceived,
    HeaderParsed,
    SecurityVerified,
    RoutedToDestination,
    DroppedMalicious,
}

#[derive(Debug, Clone)]
pub struct PacketContext {
    pub id: u64,
    pub source_ip: String,
    pub dest_ip: String,
    pub payload_len: usize,
    pub state: PacketState,
}

pub struct PacketPipeline {
    packets: HashMap<u64, PacketContext>,
}

impl PacketPipeline {
    pub fn new() -> Self {
        Self {
            packets: HashMap::new(),
        }
    }

    /// Fast refactor target: Add packet, update state, and route
    pub fn ingest_packet(&mut self, id: u64, src: &str, dest: &str, size: usize) {
        let ctx = PacketContext {
            id,
            source_ip: src.to_string(),
            dest_ip: dest.to_string(),
            payload_len: size,
            state: PacketState::IngressReceived,
        };
        self.packets.insert(id, ctx);
    }

    pub fn advance_state(&mut self, id: u64, next_state: PacketState) -> Result<(), &'static str> {
        let packet = self.packets.get_mut(&id).ok_or("Packet ID not found")?;
        packet.state = next_state;
        Ok(())
    }

    pub fn filter_by_state(&self, state: PacketState) -> Vec<&PacketContext> {
        self.packets
            .values()
            .filter(|p| p.state == state)
            .collect()
    }
}

fn main() {
    println!("=== Zed Keyboard & Refactoring Demonstration ===");

    let mut pipeline = PacketPipeline::new();
    pipeline.ingest_packet(1, "192.168.1.10", "10.0.0.1", 1024);
    pipeline.ingest_packet(2, "192.168.1.50", "10.0.0.2", 2048);

    pipeline.advance_state(1, PacketState::HeaderParsed).unwrap();
    pipeline.advance_state(1, PacketState::SecurityVerified).unwrap();
    pipeline.advance_state(2, PacketState::DroppedMalicious).unwrap();

    let dropped = pipeline.filter_by_state(PacketState::DroppedMalicious);
    println!("Dropped malicious packets count: {}", dropped.len());
    for p in dropped {
        println!("  -> Malicious packet #{} from {}", p.id, p.source_ip);
    }
}
```

## Common Pitfalls & Configuration Errors

### 1. Esc Key Delay on Linux/X11
- **Cause**: The terminal or desktop environment intercepting the `<Escape>` key for meta-key combinations.
- **Fix**: Remap `jk` or `fd` in insert mode to escape back to normal mode for instant switching:
  ```json
  {
    "context": "Editor && vim_mode == insert",
    "bindings": {
      "j k": "vim::NormalBefore"
    }
  }
  ```

### 2. Clipboard Synchronization Issues
- **Cause**: Vim mode maintaining a private register buffer detached from the system OS clipboard.
- **Fix**: Set `"use_system_clipboard": "always"` in Zed's `settings.json`.

## Complete Solutions to Exercises

### Solution 1: Vim Motion Keystroke Efficiency
1. **Changing `5000` to `2500`**:
   - Keystrokes: `ci(2500<Esc>` (Change inside parentheses, types `2500`, exits to Normal mode). Total: 8 keystrokes.
2. **Changing `from_millis` to `from_secs`**:
   - Cursor on `from_millis`: `ciwfrom_secs<Esc>` (Change inside word, types `from_secs`, exits to Normal mode). Total: 13 keystrokes.

### Solution 2: Multi-Cursor Struct Transformation
1. Select the 4 lines.
2. Press `ctrl-shift-l` (or columnar cursor `ctrl-alt-down`).
3. Press `I` (Insert at beginning of line) and type `pub `.
4. Press `$` (Jump to end of line), type `: String,` (or respective types).
5. Result:
```rust
pub struct UserRecord {
    pub username: String,
    pub email: String,
    pub organization_id: u64,
    pub created_at: i64,
}
```
