## Concept

Rust is a **statically typed** language, meaning the compiler must know the exact type of every variable at compile time. Rust categorizes its primitive data types into two groups: **Scalar Types** (single values) and **Compound Types** (multiple values grouped together).

---

### 1. Scalar Types

A **scalar type** represents a single, atomic value.

#### A. Integers (Exact Bit Widths)
Rust provides integers with explicit memory footprints:

| Bit Width | Signed (Positive/Negative) | Unsigned (Positive Only) | Range for Unsigned |
| :--- | :--- | :--- | :--- |
| **8-bit** | `i8` | `u8` | `0` to `255` |
| **16-bit** | `i16` | `u16` | `0` to `65,535` |
| **32-bit** | `i32` *(Default)* | `u32` | `0` to $\approx 4.29 \times 10^9$ |
| **64-bit** | `i64` | `u64` | `0` to $\approx 1.84 \times 10^{19}$ |
| **128-bit** | `i128` | `u128` | `0` to $\approx 3.40 \times 10^{38}$ |
| **Arch-size** | `isize` | `usize` | Target pointer size (64 bits on 64-bit CPU) |

- **`usize` / `isize`**: The size of a memory address on your computer. Used primarily for indexing into arrays and collections.
- **Number Literals**: You can write `1_000_000` (underscores for readability), `0xFF` (Hexadecimal), `0b1111_0000` (Binary), or `b'A'` (a single byte `u8` representing ASCII 65).

#### B. Floating-Point Numbers
- `f32`: 32-bit single-precision floating point.
- `f64`: 64-bit double-precision floating point (*Default*).

#### C. Booleans
- `bool`: 1 byte in size, containing either `true` or `false`.

#### D. Characters (`char`)
- `char`: Stored as **4 bytes** (32 bits) and represents a **Unicode Scalar Value**. Enclosed in single quotes: `'A'`, `'α'`, `'🦀'`. (Unlike strings, which use double quotes).

---

### 2. Compound Types

A **compound type** groups multiple values into a single container. Rust has two built-in compound types: **Tuples** and **Arrays**.

#### A. Tuples (Heterogeneous, Fixed-Size)
A **tuple** groups values of **different types** into a fixed-length unit allocated on the stack.

```rust
let endpoint: (&str, u16, bool) = ("127.0.0.1", 8080, true);

// Access via dot-index:
let ip = endpoint.0;
let port = endpoint.1;

// Access via destructuring:
let (host, port_num, is_tls) = endpoint;
```
*(Special Case: The empty tuple `()` is called the **Unit type**. It represents "nothing" or the return value of functions that return no data).*

#### B. Arrays (Homogeneous, Fixed-Size, Stack-Allocated)
An **array** is a fixed-length sequence of elements of the **exact same type**, stored contiguously on the **Stack**.

- **Type Syntax**: `[Type; Length]`
- **Creation**: `let buffer: [u8; 4] = [192, 168, 1, 1];`
- **Repeating Initializer**: `let zeros = [0u8; 1024];` (Creates an array of 1,024 zeros).

```
Array in Memory: [u8; 4]
┌─────────┬─────────┬─────────┬─────────┐
│ Byte 0  │ Byte 1  │ Byte 2  │ Byte 3  │
│   192   │   168   │    1    │    1    │
└─────────┴─────────┴─────────┴─────────┘
Index: 0       1         2         3
```

---

## Why it matters

In low-level systems programming, memory safety and binary alignment are paramount. 
- An IPv4 header or TCP packet is not an abstract concept; it is an exact sequence of `u8` bytes and `u16` fields.
- With `[u8; 4]`, Rust guarantees the 4 bytes sit directly next to each other on the CPU stack with zero memory allocation overhead.
- If your code attempts to read beyond the array bounds (`buffer[10]`), Rust stops execution immediately before an out-of-bounds memory read can occur, preventing buffer-overflow exploits (the #1 historical vulnerability in C/C++ systems).

---

## Analogy

- **Scalar Type**: A single coin in your pocket. It has a specific denomination (`u8`, `i32`).
- **Tuple**: A Swiss Army Knife. It holds a blade (`&str`), a screwdriver (`u16`), and a flashlight (`bool`). Each tool is a different shape and type, but they are bundled into one physical device.
- **Array**: An egg carton with exactly 12 pre-molded slots. Every single slot must hold the exact same type of item (an egg), and the carton's capacity is permanently fixed at 12 when manufactured.

## Code Example

```rust
fn main() {
    println!("--- 1. Scalar Types & Bit Formats ---");

    let decimal_val: u32 = 1_000_000;
    let hex_val: u8 = 0xFF;         // 255 in decimal
    let binary_val: u8 = 0b0000_1111; // 15 in decimal
    let byte_literal: u8 = b'G';     // ASCII byte 71

    let unicode_char: char = '🦀';
    let is_connected: bool = true;
    let latency_ms: f64 = 1.458;

    println!("Decimal: {}, Hex: {}, Binary: {}, Byte: {}", decimal_val, hex_val, binary_val, byte_literal);
    println!("Rust Mascot: {}, Online: {}, Latency: {}ms", unicode_char, is_connected, latency_ms);

    println!("\n--- 2. Tuples (Heterogeneous Grouping) ---");

    // Socket address tuple: (IP string, port number, is_encrypted)
    let socket_address: (&str, u16, bool) = ("10.0.0.1", 443, true);

    // Direct element access using index notation
    println!("Connecting to host: {}:{}", socket_address.0, socket_address.1);

    // Destructuring the tuple into individual named variables
    let (ip_addr, port, encrypted) = socket_address;
    println!("Destructured -> IP: {}, Port: {}, Encrypted: {}", ip_addr, port, encrypted);

    println!("\n--- 3. Arrays (Homogeneous, Stack-Allocated) ---");

    // Fixed 4-byte IPv4 address array
    let ipv4_bytes: [u8; 4] = [127, 0, 0, 1];
    println!("Loopback IP: {}.{}.{}.{}", ipv4_bytes[0], ipv4_bytes[1], ipv4_bytes[2], ipv4_bytes[3]);

    // Fast repeated initialization: 16-byte buffer filled with zeros
    let mut packet_buffer: [u8; 8] = [0; 8];

    // Writing header magic bytes into the buffer
    packet_buffer[0] = b'H'; // 'H'
    packet_buffer[1] = b'T'; // 'T'
    packet_buffer[2] = b'T'; // 'T'
    packet_buffer[3] = b'P'; // 'P'

    println!("Buffer total bytes (len): {}", packet_buffer.len());
    println!("First 4 Header Bytes: {:?}", &packet_buffer[0..4]);
}
```

## Common Mistakes

### 1. Confusing Array Type Syntax with Array Literals
A beginner writes `[u8, 4]` instead of `[u8; 4]` when declaring an array type.

**Broken Code:**
```rust
let data: [u8, 4] = [1, 2, 3, 4]; // Error: comma used instead of semicolon
```

**Compiler Output:**
```text
error: expected `;`, found `,`
 --> src/main.rs:1:14
  |
1 | let data: [u8, 4] = [1, 2, 3, 4];
  |              ^ help: use a semicolon to separate the type and length: `;`
```

---

### 2. Array Index Out-of-Bounds
Accessing an index equal to or greater than the array's fixed length.

**Broken Code:**
```rust
fn main() {
    let status_codes = [200, 404, 500]; // Length is 3 (indices: 0, 1, 2)
    let invalid = status_codes[3];      // Error: Index 3 does not exist!
}
```

**Compiler Output:**
```text
error: this operation will panic at runtime
 --> src/main.rs:3:19
  |
3 |     let invalid = status_codes[3];
  |                   ^^^^^^^^^^^^^^^ index out of bounds: the length is 3 but the index is 3
```

---

### 3. Single Quotes (`'`) vs. Double Quotes (`"`)
Using double quotes for a single `char` or single quotes for a string.

**Broken Code:**
```rust
let character: char = "A"; // Error: "A" is a &str, not a char!
```

*How to fix*: Use `'A'` for a 4-byte `char`, and `"A"` for a string slice `&str`.

## Exercises

### Exercise 1 (Type Identification)
Provide the exact Rust type signature (e.g., `(u8, bool)`, `[f64; 3]`, `char`, `u16`) for each of the following:
1. A 4-element array of unsigned 8-bit integers representing an IPv4 subnet mask (`[255, 255, 255, 0]`).
2. A tuple storing an HTTP method name `"POST"`, a status code `201`, and the response time `34.5` ms.
3. A single Greek character `'Ω'`.

---

### Exercise 2 (Tuple Destructuring)
Given the following tuple representing a database configuration:
```rust
let db_config: (&str, u16, &str, u32) = ("db.internal", 5432, "postgres", 100);
```
Write code that destructures this tuple into four variables (`host`, `port`, `username`, `max_pool`) and prints:
```text
Host: db.internal:5432 | User: postgres | Pool: 100
```

---

### Exercise 3 (Fixed Buffer Manipulation)
Write a program that:
1. Allocates a mutable stack array `packet_header` of `6` bytes initialized to all zeros (`[0u8; 6]`).
2. Sets the first 2 bytes to `b'O'` and `b'K'`.
3. Sets bytes at index 4 and 5 to `1` and `0`.
4. Prints the entire array using the debug formatter `println!("{:?}", packet_header);`.

---

## Solutions

### Solution to Exercise 1
1. `[u8; 4]` — A fixed-size array of 4 unsigned 8-bit integers.
2. `(&str, u16, f64)` — A tuple grouping a string slice, a 16-bit unsigned integer, and a 64-bit float.
3. `char` — A 4-byte Unicode scalar character.

---

### Solution to Exercise 2
```rust
fn main() {
    let db_config: (&str, u16, &str, u32) = ("db.internal", 5432, "postgres", 100);

    let (host, port, username, max_pool) = db_config;

    println!("Host: {}:{} | User: {} | Pool: {}", host, port, username, max_pool);
}
```

---

### Solution to Exercise 3
```rust
fn main() {
    let mut packet_header: [u8; 6] = [0u8; 6];

    packet_header[0] = b'O';
    packet_header[1] = b'K';
    packet_header[4] = 1;
    packet_header[5] = 0;

    println!("{:?}", packet_header);
}
```
