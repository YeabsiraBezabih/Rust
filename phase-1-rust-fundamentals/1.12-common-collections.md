## Concept

Unlike fixed-size stack arrays (`[T; N]`), real-world systems need data structures that can dynamically grow and shrink at runtime. Rust's standard library provides three primary heap-allocated collections: **`Vec<T>`**, **`String`**, and **`HashMap<K, V>`**.

---

### 1. Dynamic Arrays: `Vec<T>`

A **Vector** (`Vec<T>`) is a growable, contiguous list of items of type `T` allocated on the **Heap**.

```
STACK (24 Bytes)                    HEAP (Dynamic Buffer)
┌───────────────────────┐          ┌───────┬───────┬───────┬───────┐
│ ptr: 0x7FFF00         │ ───────> │  101  │  102  │  103  │  ...  │
│ len: 3 (elements)     │          └───────┴───────┴───────┴───────┘
│ cap: 4 (capacity)     │          Capacity reserves space for 4 items
└───────────────────────┘
```

- **`len`**: The number of elements currently in the vector.
- **`cap`**: The total number of elements the allocated heap buffer can hold before needing to reallocate.
- **Pre-allocation (`Vec::with_capacity(N)`)**: Avoids repeated, expensive heap reallocations when you know the approximate number of items in advance.
- **Safe Element Access (`.get()`)**: `vec[index]` panics if `index >= len`. `vec.get(index)` returns `Option<&T>`, allowing safe error handling.

---

### 2. UTF-8 Text: `String` and `&str`

Rust strings are **guaranteed to be valid UTF-8 sequences**.

- **`String`**: An owned, growable heap buffer (essentially a `Vec<u8>` under the hood).
- **`&str` (String Slice)**: A borrowed reference to a sequence of UTF-8 bytes (stored in static memory, stack, or heap).

#### Why Rust Forbids String Indexing (`s[0]`):
In UTF-8, characters are encoded using **1 to 4 bytes**. For example, `'A'` is 1 byte, while `'🦀'` is 4 bytes. If Rust allowed `s[0]`, accessing a 4-byte emoji by byte index would slice the character in half, producing corrupted binary data. 

To inspect characters, you explicitly iterate using `.chars()` (Unicode scalar values) or `.bytes()` (raw bytes).

---

### 3. Key-Value Maps: `HashMap<K, V>`

A `HashMap<K, V>` stores associations between unique **Keys** of type `K` and **Values** of type `V` using a hashing algorithm, offering $O(1)$ average lookup and insertion time.

Must be imported: `use std::collections::HashMap;`.

#### The `.entry()` API (Idiomatic Upsert):
The `.entry()` API provides an atomic check-and-insert operation without redundant hash lookups:

```rust
let mut counts = HashMap::new();
// If "GET" exists, return &mut count; if not, insert 0 and return &mut count:
*counts.entry("GET").or_insert(0) += 1;
```

---

## Why it matters

In high-performance networking and backend systems:
- `Vec<u8>` is the fundamental byte buffer for streaming data over TCP sockets.
- `String` models URL paths, headers, and protocol commands.
- `HashMap<String, String>` stores parsed HTTP request headers and URL routing tables. 

Using `Vec::with_capacity()` and `HashMap::with_capacity()` eliminates memory reallocation overhead during high-traffic spikes.

---

## Analogy

- **`Vec<T>`**: An expandable accordion folder. When it runs out of space, the OS transparently buys a folder twice as large, moves all papers over, and shreds the old folder.
- **`String` vs `&str`**: A `String` is a notebook you own and can write new sentences into. A `&str` is a clear bookmark placed over three lines of text so someone else can read it without tearing out the page.
- **`HashMap<K, V>`**: A wall of post office boxes. Each box has a nameplate (`Key`). The postal clerk computes the exact box location instantly and puts the mail (`Value`) inside in $O(1)$ time.

## Code Example

```rust
use std::collections::HashMap;

fn main() {
    println!("--- 1. Vectors (Vec<T>) with Capacity Pre-allocation ---");

    // Pre-allocating space for 8 packet IDs on the heap to prevent reallocations
    let mut packet_queue: Vec<u32> = Vec::with_capacity(8);
    println!("Initial -> Len: {}, Cap: {}", packet_queue.len(), packet_queue.capacity());

    packet_queue.push(1001);
    packet_queue.push(1002);
    packet_queue.push(1003);

    println!("After pushes -> Len: {}, Cap: {}", packet_queue.len(), packet_queue.capacity());

    // Safe lookup using .get() returning Option<&T>
    match packet_queue.get(2) {
        Some(&id) => println!("Packet at index 2: {}", id),
        None => println!("No packet at index 2"),
    }

    // Iterating and mutating in place
    for packet_id in &mut packet_queue {
        *packet_id += 10; // Dereference to mutate the value
    }
    println!("Updated queue: {:?}", packet_queue);

    println!("\n--- 2. String Manipulation and Slicing ---");

    let mut http_status = String::from("HTTP/1.1");
    http_status.push(' ');          // Push a single char
    http_status.push_str("200 OK"); // Push a string slice

    println!("Constructed status line: {}", http_status);

    // Iterating over Unicode characters safely
    let emoji_tag = "Status: 🚀 Online";
    print!("Characters: ");
    for c in emoji_tag.chars() {
        print!("'{}' ", c);
    }
    println!();

    println!("\n--- 3. HashMaps with Entry API ---");

    // Creating an HTTP header lookup table
    let mut headers: HashMap<String, String> = HashMap::new();
    headers.insert(String::from("Host"), String::from("api.domain.internal"));
    headers.insert(String::from("Content-Type"), String::from("application/json"));

    // Safe retrieval with .get()
    if let Some(content_type) = headers.get("Content-Type") {
        println!("Header Content-Type: {}", content_type);
    }

    // Frequency counting using the .entry() API
    let request_methods = ["GET", "POST", "GET", "GET", "DELETE", "POST"];
    let mut method_counts: HashMap<&str, u32> = HashMap::new();

    for &method in &request_methods {
        // Find existing count or insert 0, then increment
        let count_ref = method_counts.entry(method).or_insert(0);
        *count_ref += 1;
    }

    println!("Request Method Frequency: {:?}", method_counts);
}
```

## Common Mistakes

### 1. Mutating a Vector While Holding a Reference to an Element
Modifying a vector can cause it to reallocate its heap buffer, which would invalidate any existing references. The borrow checker prevents this.

**Broken Code:**
```rust
fn main() {
    let mut queue = vec![10, 20, 30];
    let first = &queue[0]; // Immutable borrow begins
    queue.push(40);        // Error: Mutable borrow while `first` exists!
    println!("First element: {}", first);
}
```

**Compiler Output:**
```text
error[E0502]: cannot borrow `queue` as mutable because it is also borrowed as immutable
 --> src/main.rs:4:5
  |
3 |     let first = &queue[0];
  |                  ----- immutable borrow occurs here
4 |     queue.push(40);
  |     ^^^^^^^^^^^^^^ mutable borrow occurs here
5 |     println!("First element: {}", first);
  |                                   ----- immutable borrow later used here
```

---

### 2. Attempting Direct Integer Indexing on Strings
Writing `my_string[0]` to get the first character.

**Broken Code:**
```rust
let word = String::from("Rust");
let first_char = word[0]; // Error: `String` cannot be indexed by integer
```
*How to fix*: Use `word.chars().next()` or `&word[0..1]`.

## Solutions

### Solution to Exercise 1
```rust
fn safe_remove_first(queue: &mut Vec<String>) -> Option<String> {
    if queue.is_empty() {
        None
    } else {
        Some(queue.remove(0))
    }
}

fn main() {
    let mut requests = vec![String::from("req1"), String::from("req2")];

    println!("Removed: {:?}", safe_remove_first(&mut requests));
    println!("Removed: {:?}", safe_remove_first(&mut requests));
    println!("Removed: {:?}", safe_remove_first(&mut requests));
}
```

### Solution to Exercise 2
```rust
use std::collections::HashMap;

fn main() {
    let responses = [200, 200, 404, 500, 200, 404, 200, 503];
    let mut frequency_map: HashMap<u16, u32> = HashMap::new();

    for &code in &responses {
        *frequency_map.entry(code).or_insert(0) += 1;
    }

    println!("Status Code Frequencies: {:?}", frequency_map);
}
```

### Solution to Exercise 3
```rust
use std::collections::HashMap;

fn normalize_headers(raw: HashMap<String, String>) -> HashMap<String, String> {
    let mut normalized = HashMap::with_capacity(raw.len());
    for (key, value) in raw {
        normalized.insert(key.to_lowercase(), value);
    }
    normalized
}

fn main() {
    let mut raw_headers = HashMap::new();
    raw_headers.insert(String::from("Content-Type"), String::from("application/json"));
    raw_headers.insert(String::from("AUTHORIZATION"), String::from("Bearer 123"));

    let clean = normalize_headers(raw_headers);
    println!("Normalized Headers: {:?}", clean);
}
```
