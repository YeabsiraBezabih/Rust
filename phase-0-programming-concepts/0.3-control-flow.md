# Lesson 0.3: Control Flow: Branching and Loops

## Concept

By default, a computer executes code **sequentially**—one line after another, from top to bottom. 

**Control flow** refers to the mechanisms that alter this straight-line execution, allowing the CPU to make decisions (skip or choose specific blocks of code) or repeat tasks multiple times.

---

### 1. Conditional Branching (`if`, `else if`, `else`)

Branching allows your program to evaluate a **condition** (an expression that results in a `bool`: either `true` or `false`) and execute different blocks of code depending on the result.

```
                  ┌──────────────────────┐
                  │ Is status_code == 200?│
                  └──────────┬───────────┘
                             │
               ┌─────────────┴─────────────┐
             True                        False
               ▼                           ▼
     ┌──────────────────┐        ┌──────────────────┐
     │  Handle Success  │        │   Handle Error   │
     └──────────────────┘        └──────────────────┘
```

#### Comparison Operators:
- `==` (is equal to)
- `!=` (is not equal to)
- `<` (less than), `>` (greater than)
- `<=` (less than or equal to), `>=` (greater than or equal to)

In Rust, the condition **must evaluate to a strict `bool`**. Unlike some other languages, numbers like `0` or `1` and empty text strings are *not* automatically converted to `true` or `false`.

#### `if` as an Expression:
In Rust, `if` blocks can produce a value that you can assign directly to a variable:

```rust
let is_authenticated = true;
let access_level = if is_authenticated { "Admin" } else { "Guest" };
```

### 2. Repetition and Loops

When you need to repeat an action, Rust provides three primary loop constructs:

#### A. The `loop` Keyword (Infinite Loop)
`loop` tells the CPU to repeat a block of code forever until it encounters the `break` keyword. This is the foundation of network servers that must run indefinitely, waiting for client connections.

```rust
let mut connection_attempts = 0;

loop {
    connection_attempts += 1;
    if connection_attempts == 3 {
        break; // Exits the loop immediately
    }
}
```

#### B. The `while` Loop (Conditional Loop)
A `while` loop checks a condition before every iteration. As long as the condition evaluates to `true`, the loop continues. As soon as it becomes `false`, the loop ends.

```rust
let mut remaining_packets = 3;

while remaining_packets > 0 {
    remaining_packets -= 1;
}
```

#### C. The `for` Loop (Range-Based Loop)
A `for` loop executes a fixed number of times over a sequence or range of numbers. 
- `1..5` means numbers `1, 2, 3, 4` (exclusive of 5).
- `1..=5` means numbers `1, 2, 3, 4, 5` (inclusive of 5).

```rust
for retry_count in 1..=3 {
    // Executes 3 times: retry_count will be 1, then 2, then 3
}
```

#### Loop Control Keywords:
- `break`: Immediately exits the loop.
- `continue`: Skips the rest of the current iteration and jumps directly to the next iteration.

---

## Why it matters

Control flow is the backbone of systems architecture:
1. **Network Servers**: An HTTP server runs an infinite `loop` to accept incoming TCP socket connections.
2. **Protocol Parsing**: When parsing HTTP headers, the server checks `if` the line starts with `"Content-Length:"` or `"Authorization:"` and routes the request accordingly.
3. **Resilience**: Distributed systems use `while` loops to retry failed database queries with backoff limits.

---

## Analogy

- **Branching (`if`/`else`)**: A railway track switch. The track splits into two directions. If the signal is green (`true`), the train rolls onto Track A; otherwise, it is diverted to Track B.
- **Loops**: An automated telephone redialer. If the line is busy, the redialer loops and tries again up to 5 times. Once connected (`break`), it stops redialing and begins the conversation.

## Code Example

```rust
fn main() {
    let http_status_code: u16 = 404;

    // 1. Conditional Branching
    if http_status_code == 200 {
        println!("Request succeeded: 200 OK");
    } else if http_status_code == 404 {
        println!("Resource missing: 404 Not Found");
    } else if http_status_code == 500 {
        println!("Server malfunction: 500 Internal Server Error");
    } else {
        println!("Received unhandled status code: {}", http_status_code);
    }

    println!("--- Network Reconnection Routine ---");

    // 2. Simulated Network Retry with `for` and `break`
    let max_retries = 3;
    let target_server_online = false;

    for attempt in 1..=max_retries {
        println!("Attempting connection to remote host (attempt {}/{})...", attempt, max_retries);

        if target_server_online {
            println!("Successfully connected!");
            break; // Stop retrying once connected
        } else {
            println!("Connection failed.");
        }
    }

    println!("--- Queue Processing with `while` ---");

    // 3. Queue Drain with `while`
    let mut pending_jobs: u32 = 3;

    while pending_jobs > 0 {
        println!("Processing job. Remaining jobs in queue: {}", pending_jobs);
        pending_jobs -= 1; // Decrement counter by 1
    }

    println!("All jobs processed successfully.");
}
```

## Common Mistakes

### 1. Using Assignment (`=`) Instead of Equality Check (`==`)
In mathematics, `=` means equal. In programming, `=` assigns a value to a variable, whereas `==` checks if two values are equal.

**Broken Code:**
```rust
fn main() {
    let status = 200;
    if status = 200 { // Error!
        println!("OK");
    }
}
```

**Compiler Output:**
```text
error[E0308]: mismatched types
 --> src/main.rs:3:8
  |
3 |     if status = 200 {
  |        ^^^^^^^^^^^^ expected `bool`, found `()`
```
*Why it happens*: Rust prevents you from accidentally reassigning variables inside condition checks.

---

### 2. Expecting Non-Booleans to Be "Truthy" or "Falsy"
In some other languages, `0` is treated as false and non-zero numbers are treated as true. In Rust, conditions **must** be boolean expressions.

**Broken Code:**
```rust
fn main() {
    let error_count = 0;
    if error_count { // Error!
        println!("Errors present");
    }
}
```

**Compiler Output:**
```text
error[E0308]: mismatched types
 --> src/main.rs:3:8
  |
3 |     if error_count {
  |        ^^^^^^^^^^^ expected `bool`, found integer
```
*How to fix*: Explicitly check `if error_count > 0`.

---

### 3. Forgetting to Update the Loop Counter (Infinite Loop)
A `while` loop whose condition never changes will freeze the CPU in an endless cycle.

**Broken Code:**
```rust
fn main() {
    let mut count = 3;
    while count > 0 {
        println!("Count: {}", count);
        // Forgot: count -= 1; -> The loop will never finish!
    }
}
```

## Exercises

### Exercise 1 (HTTP Status Classifier)
Write a program that:
1. Declares a variable `status_code: u16 = 403`.
2. Uses an `if` / `else if` / `else` chain to print:
   - `"Access Granted"` if `status_code` is `200`.
   - `"Forbidden: Permission Denied"` if `status_code` is `403`.
   - `"Server Error"` if `status_code` is `500`.
   - `"Unknown Status Code: <value>"` for any other status code.

---

### Exercise 2 (Spotting the Loop Flaw)
Examine this retry loop. Explain why it fails to stop when `connection_successful` becomes `true`:

```rust
fn main() {
    let mut connection_successful = false;
    let mut attempts = 0;

    while attempts < 5 {
        attempts += 1;
        if attempts == 3 {
            connection_successful = true;
        }
        println!("Attempt: {}, Success: {}", attempts, connection_successful);
    }
}
```

---

### Exercise 3 (Packet Rate Limiter)
Write a program using a `for` loop that iterates over packet IDs from `1` to `6` (inclusive):
1. If the packet ID is `3`, print `"Packet 3 dropped (corrupted)"` and use `continue` to skip the rest of the loop for that packet.
2. Otherwise, print `"Packet <ID> processed successfully"`.

---

## Solutions

### Solution to Exercise 1
```rust
fn main() {
    let status_code: u16 = 403;

    if status_code == 200 {
        println!("Access Granted");
    } else if status_code == 403 {
        println!("Forbidden: Permission Denied");
    } else if status_code == 500 {
        println!("Server Error");
    } else {
        println!("Unknown Status Code: {}", status_code);
    }
}
```

---

### Solution to Exercise 2
**Explanation**: The `while` loop checks only `while attempts < 5`. Even when `connection_successful` becomes `true` on attempt 3, the loop has no condition check or `break` statement to stop it. It continues running attempts 4 and 5 until `attempts` reaches 5.

**Fix**: Add `if connection_successful { break; }` or change the loop condition to `while attempts < 5 && !connection_successful`.

---

### Solution to Exercise 3
```rust
fn main() {
    for packet_id in 1..=6 {
        if packet_id == 3 {
            println!("Packet 3 dropped (corrupted)");
            continue; // Skip the rest of this iteration
        }

        println!("Packet {} processed successfully", packet_id);
    }
}
```
