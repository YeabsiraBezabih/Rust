## Concept

When running backend microservices in production, diagnosing network issues (connection timeouts, DNS resolution failures, port conflicts, firewall drops) is a core responsibility of systems and backend engineers.

Linux handles networking through the kernel's **Netfilter Subsystem**, the **Routing Table**, and user-space diagnostics tools (`ip`, `ss`, `dig`, `tcpdump`).

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    Linux Network Ingress & Netfilter Pipeline                │
├──────────────────────────────────────────────────────────────────────────────┤
│  Incoming Network Packet (Ethernet Frame on `eth0`)                          │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ NIC Driver & Ring Buffer (DMA to Host RAM)                             │  │
│  └───────────────────┬────────────────────────────────────────────────────┘  │
│                      │ Hardware Interrupt / NAPI Polling                     │
│                      ▼                                                       │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ Netfilter PREROUTING Chain (NAT / Destination Port Redirection)        │  │
│  └───────────────────┬────────────────────────────────────────────────────┘  │
│                      │ Routing Decision (Is packet for local host?)          │
│                      ▼                                                       │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ Netfilter INPUT Chain (`ufw` / `nftables` / `iptables` Firewall Rules) │  │
│  │   • ALLOW Port 22 (SSH), 80 (HTTP), 443 (HTTPS)                        │  │
│  │   • DROP all unauthorized ingress ports (e.g. 5432, 6379, 23)          │  │
│  └───────────────────┬────────────────────────────────────────────────────┘  │
│                      │ Kernel TCP/IP Protocol Stack                          │
│                      ▼                                                       │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ Application Socket Receive Queue (`TcpListener::accept()` on 8080)     │  │
│  └────────────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 1. The Essential Linux Network Diagnostic Toolbelt

Modern Linux distributions deprecate `netstat` and `ifconfig` in favor of `iproute2` (`ip`, `ss`):

| Modern Command | Legacy Deprecated | Purpose |
| :--- | :--- | :--- |
| `ip addr show` | `ifconfig` | View network interfaces and assigned IPv4/IPv6 IPs. |
| `ip route show`| `route -n` | Inspect kernel routing table and default gateway. |
| `ss -tulpn` | `netstat -tulpn` | List all listening TCP/UDP ports and associated PIDs. |
| `dig +short api.com`| `nslookup` | Query DNS records with latency and authoritative nameservers. |
| `tcpdump -nn -i any port 80` | N/A | Capture and inspect live packet traffic on wire. |
| `curl -Iv https://api.com` | N/A | Inspect TLS handshake, certificates, and HTTP response headers. |

### 2. DNS Resolution Flow: `/etc/resolv.conf` & `systemd-resolved`

When your Rust backend queries `reqwest::get("https://api.stripe.com")`, the system follows this resolution path:

1. **`/etc/nsswitch.conf`**: Configures lookup order (typically: `hosts: files dns`).
2. **`/etc/hosts`**: Local static host-to-IP overrides (e.g. `127.0.0.1 localhost`).
3. **`/etc/resolv.conf`**: Points to upstream DNS nameservers (or local stub resolver `127.0.0.53` managed by `systemd-resolved`).

### 3. Server Firewall Hardening: `ufw` & `nftables`

Default-deny firewalling protects backend nodes from malicious probes:

#### Simple Server Configuration with UFW:
```bash
# 1. Default: Block all incoming, allow all outgoing
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 2. Allow essential service ports
sudo ufw allow 22/tcp   # SSH
sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS

# 3. Allow internal VPC traffic for Postgres (e.g. from 10.0.1.0/24 subnet only!)
sudo ufw allow from 10.0.1.0/24 to any port 5432 proto tcp

# 4. Enable and verify
sudo ufw enable
sudo ufw status verbose
```

### 4. High-Throughput Linux Kernel TCP Tuning (`/etc/sysctl.conf`)

For servers handling 100,000+ concurrent connections:

```ini
# /etc/sysctl.conf
# Increase max backlog of pending connections
net.core.somaxconn = 65535
net.ipv4.tcp_max_syn_backlog = 16384

# Expand ephemeral port range for outgoing connections
net.ipv4.ip_local_port_range = 1024 65535

# Fast recycling of TIME_WAIT sockets for reverse proxies
net.ipv4.tcp_tw_reuse = 1

# Increase socket buffer memory limits
net.core.rmem_max = 16777216
net.core.wmem_max = 16777216
```

Apply immediately with: `sudo sysctl -p`.

## Why It Matters in Systems & Backend Engineering

1. **Port Conflict Resolution**: Running `ss -tulpn | grep 8080` instantly reveals which zombie process is holding a port and preventing your server from starting.
2. **Preventing Outbound Connection Exhaustion**: When a microservice calls external APIs under heavy load, default Linux ephemeral port settings can exhaust available sockets, causing `EADDRNOTAVAIL` errors without proper kernel tuning.
3. **Internal VPC Security**: Firewall rules ensure that databases and caching nodes reject any traffic not originating from authorized application servers.

## Real-World Analogy

- **The Linux Network Interface (`eth0`)** is the front security gate of an airport.
- **The Netfilter Firewall (`ufw`)** is the border control checkpoint: every passenger (**Packet**) is checked against the entry rules (**Port Allowlist**). Unauthorized passengers are turned away before entering the terminal.
- **`ss -tulpn`** is the flight departure board: it displays every active gate (**Port**) and the assigned airline crew (**Process PID**).

## Complete, Compilable Code Example

The following program implements a **High-Performance TCP Port Scanner & Health Verifier** in pure Rust to audit reachable ports across servers:

```rust
use std::net::{SocketAddr, TcpStream, ToSocketAddrs};
use std::time::Duration;

#[derive(Debug, PartialEq, Eq)]
pub enum PortStatus {
    Open,
    ClosedOrFiltered,
}

pub struct NetworkAuditor {
    timeout: Duration,
}

impl NetworkAuditor {
    pub fn new(timeout_ms: u64) -> Self {
        Self {
            timeout: Duration::from_millis(timeout_ms),
        }
    }

    /// Check if a remote host port is open and accepting TCP handshakes
    pub fn check_port(&self, host: &str, port: u16) -> PortStatus {
        let addr_str = format!("{}:{}", host, port);
        
        match addr_str.to_socket_addrs() {
            Ok(mut addrs) => {
                if let Some(addr) = addrs.next() {
                    match TcpStream::connect_timeout(&addr, self.timeout) {
                        Ok(_) => PortStatus::Open,
                        Err(_) => PortStatus::ClosedOrFiltered,
                    }
                } else {
                    PortStatus::ClosedOrFiltered
                }
            }
            Err(_) => PortStatus::ClosedOrFiltered,
        }
    }

    /// Resolves DNS hostname to all associated IPv4/IPv6 addresses
    pub fn resolve_dns(&self, host: &str) -> Result<Vec<SocketAddr>, std::io::Error> {
        let addr_str = format!("{}:80", host);
        Ok(addr_str.to_socket_addrs()?.collect())
    }
}

fn main() {
    println!("=== Linux Server Networking & Port Audit Engine ===\n");

    let auditor = NetworkAuditor::new(500);

    // 1. Audit Local Loopback Ports
    println!("Auditing Local Server Ports (127.0.0.1):");
    let test_ports = [22, 80, 443, 5432, 6379, 8080];
    for &port in &test_ports {
        let status = auditor.check_port("127.0.0.1", port);
        println!("  Port {:<5} => {:?}", port, status);
    }

    // 2. Perform DNS Resolution test on public domain
    println!("\nResolving DNS for 'dns.google' via Linux Subsystem:");
    match auditor.resolve_dns("dns.google") {
        Ok(addrs) => {
            for addr in addrs {
                println!("  -> Resolved IP: {}", addr.ip());
            }
        }
        Err(e) => eprintln!("DNS Resolution failed: {}", e),
    }
}
```

## Common Pitfalls & Server Mistakes

### 1. `Address already in use` (`EADDRINUSE`)
- **Cause**: Restarting a server immediately after shutdown while sockets are lingering in `TIME_WAIT` state, or a rogue zombie process still holding the socket.
- **Fix**: Enable `SO_REUSEADDR` / `SO_REUSEPORT` on the listening socket in Rust (`socket2` crate) and identify culprits with `ss -tulpn | grep <port>`.

### 2. Accidental SSH Lockout with UFW
- **Cause**: Running `sudo ufw default deny incoming` and `sudo ufw enable` without first running `sudo ufw allow 22/tcp`.
- **Fix**: Always allow your SSH port before enabling the firewall!

## Complete Solutions to Exercises

### Solution 1: UFW Rule Generator
```rust
pub struct FirewallRule {
    pub port: u16,
    pub protocol: &'static str,
    pub allowed_source: Option<String>,
}

impl FirewallRule {
    pub fn to_ufw_command(&self) -> String {
        if let Some(ref src) = self.allowed_source {
            format!("ufw allow from {} to any port {} proto {}", src, self.port, self.protocol)
        } else {
            format!("ufw allow {}/{}", self.port, self.protocol)
        }
    }
}

#[test]
fn test_ufw_generation() {
    let public_http = FirewallRule {
        port: 80,
        protocol: "tcp",
        allowed_source: None,
    };
    assert_eq!(public_http.to_ufw_command(), "ufw allow 80/tcp");

    let restricted_pg = FirewallRule {
        port: 5432,
        protocol: "tcp",
        allowed_source: Some("10.0.1.0/24".to_string()),
    };
    assert_eq!(restricted_pg.to_ufw_command(), "ufw allow from 10.0.1.0/24 to any port 5432 proto tcp");
}
```

### Solution 2: Socket Statistics (`ss`) Output Parser
```rust
pub fn parse_listening_port(ss_line: &str) -> Option<u16> {
    for token in ss_line.split_whitespace() {
        if let Some(pos) = token.rfind(':') {
            let port_part = &token[pos + 1..];
            if let Ok(port) = port_part.parse::<u16>() {
                return Some(port);
            }
        }
    }
    None
}

#[test]
fn test_ss_parser() {
    let line = "LISTEN 0 128 0.0.0.0:8080 0.0.0.0:* users:((\"rust-api\",pid=1042,fd=3))";
    assert_eq!(parse_listening_port(line), Some(8080));
}
```
