## Concept

Historically, modifying or observing Linux kernel behavior required either compiling a custom **Kernel Module (`.ko`)**—risking machine-crashing kernel panics on any bug—or modifying kernel source code directly.

**Extended Berkeley Packet Filter (eBPF)** transforms the Linux kernel into a programmable platform: it allows developers to execute **sandboxed, event-driven bytecode directly inside the Linux kernel** at bare-metal speeds with mathematical safety guarantees enforced by the in-kernel verifier.

With the **Aya** pure-Rust eBPF framework, both the in-kernel probe and the user-space daemon are written in **100% pure Rust** (no C compiler or `libbpf` toolchains required!).

### 1. The eBPF Program Lifecycle

1. **Compilation**: The kernel-space Rust code (compiled with `#![no_std]` targeting `bpfel-unknown-none`) produces eBPF bytecode.
2. **Verification**: The Linux kernel verifier analyzes the bytecode:
   - Proves mathematically that all loops are bounded.
   - Proves every memory dereference is within valid bounds.
   - Proves no uninitialized memory is read.
3. **JIT Compilation**: The verified bytecode is compiled into native machine code (x86_64 or ARM64) on the fly.
4. **Hook Attachment**: The program is attached to kernel hooks (e.g. `kprobes`, `tracepoints`, `XDP`, `cgroups`, or `tc`).

---

### 2. Common eBPF Program Types

| Program Type | Hook Point | Primary Use Case |
| :--- | :--- | :--- |
| **XDP (eXpress Data Path)** | Network driver level before OS allocates `sk_buff` | Sub-microsecond DDoS mitigation, packet routing, firewalls. |
| **Tracepoints** | Stable static kernel tracepoints (`sys_enter_execve`) | Auditing syscalls, security monitoring, disk I/O tracing. |
| **Kprobes / Kretprobes** | Any dynamic kernel function entry / return | Deep kernel debugging, internal latency profiling. |
| **TC (Traffic Control)** | Kernel network stack ingress/egress | Bandwidth shaping, service mesh proxying (Cilium). |
| **LSM (Security Module)** | Kernel security decision hooks | Runtime container protection, blocking malware execution. |

---

### 3. eBPF Maps & Ring Buffers

eBPF programs cannot issue standard system calls. They share data with user space using **eBPF Maps**:
- **`BPF_MAP_TYPE_HASH` / `ARRAY`**: Key-value stores for blocklists, routing tables, and counters.
- **`BPF_MAP_TYPE_RINGBUF`**: High-performance multi-producer, single-consumer lock-free ring buffer for streaming kernel events to user space with zero allocations.

---

## Why It Matters in Systems & Backend Engineering

1. **Sub-Microsecond Observability**: Trace database query latency, network packet loss, and CPU scheduling delays with near-zero runtime overhead.
2. **Next-Gen Cloud Networking (Cilium / Cloudflare)**: High-speed edge routers use eBPF/XDP to drop millions of malicious DDoS packets per second directly at the NIC driver layer.
3. **Runtime Security Agents (Falco / Tetragon)**: Intercept and neutralize unauthorized container process execution in kernel space before the binary runs.

---

## Real-World Analogy

- **A Linux Kernel Module (`.ko`)** is like hiring an unsupervised contractor to rewire your building's master electrical panel: a single crossed wire causes a short circuit that burns the entire building down (**Kernel Panic**).
- **An eBPF Program** is like uploading a verified smart-applet to an isolated controller on the electrical panel: a city building inspector (**The Verifier**) proves every circuit is safe before allowing it to run.

## Complete, Compilable Code Example

The following program provides a **Pure Rust eBPF Kernel Simulator** modeling XDP packet filtering, shared hash maps, and lock-free ring buffer event streaming:

```rust
use std::collections::HashMap;
use std::sync::{Arc, Mutex};
use std::time::{SystemTime, UNIX_EPOCH};

/// Packed binary event emitted from eBPF Kernel space to User space via RingBuffer
#[repr(C)]
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct KernelSyscallEvent {
    pub timestamp_ns: u64,
    pub pid: u32,
    pub uid: u32,
    pub syscall_id: u32,
    pub comm: [u8; 16],
    pub return_value: i64,
}

impl KernelSyscallEvent {
    pub fn new(pid: u32, uid: u32, syscall_id: u32, comm_str: &str, ret: i64) -> Self {
        let mut comm = [0u8; 16];
        let bytes = comm_str.as_bytes();
        let len = bytes.len().min(15);
        comm[..len].copy_from_slice(&bytes[..len]);

        let timestamp_ns = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .unwrap()
            .as_nanos() as u64;

        Self {
            timestamp_ns,
            pid,
            uid,
            syscall_id,
            comm,
            return_value: ret,
        }
    }

    pub fn process_name(&self) -> &str {
        let null_pos = self.comm.iter().position(|&b| b == 0).unwrap_or(self.comm.len());
        std::str::from_utf8(&self.comm[..null_pos]).unwrap_or("<unknown>")
    }
}

/// Simulated eBPF Hash Map
pub struct EbpfMap<K, V> {
    data: Arc<Mutex<HashMap<K, V>>>,
}

impl<K: std::hash::Hash + Eq + Clone, V: Clone> EbpfMap<K, V> {
    pub fn new() -> Self {
        Self { data: Arc::new(Mutex::new(HashMap::new())) }
    }

    pub fn insert(&self, key: K, val: V) {
        self.data.lock().unwrap().insert(key, val);
    }

    pub fn lookup(&self, key: &K) -> Option<V> {
        self.data.lock().unwrap().get(key).cloned()
    }
}

/// Simulated XDP Action Verdicts
#[derive(Debug, PartialEq, Eq)]
pub enum XdpVerdict {
    Pass,
    Drop,
    Redirect,
}

/// Simulated XDP Driver-Level Ingress Packet Filter
pub fn xdp_firewall_hook(packet: &[u8], blocklist: &EbpfMap<[u8; 4], bool>) -> XdpVerdict {
    // IPv4 minimum packet size: 20 bytes
    if packet.len() < 20 {
        return XdpVerdict::Drop;
    }

    // Source IP is at bytes 12..16 in IPv4 header
    let src_ip: [u8; 4] = [packet[12], packet[13], packet[14], packet[15]];

    if let Some(is_blocked) = blocklist.lookup(&src_ip) {
        if is_blocked {
            return XdpVerdict::Drop; // Dropped instantly at the NIC driver!
        }
    }

    XdpVerdict::Pass
}

fn main() {
    println!("=== Linux Kernel Tracing & eBPF Observability Engine ===\n");

    // 1. Populate eBPF IP Blocklist Map
    let blocked_ips = EbpfMap::<[u8; 4], bool>::new();
    blocked_ips.insert([198, 51, 100, 42], true); // Block malicious attack IP

    // 2. Test XDP Ingress Filter
    let mut clean_packet = vec![0u8; 24];
    clean_packet[12..16].copy_from_slice(&[10, 0, 1, 50]); // Source: 10.0.1.50
    let clean_verdict = xdp_firewall_hook(&clean_packet, &blocked_ips);
    println!("Ingress Packet from 10.0.1.50   ──► XDP Verdict: {:?}", clean_verdict);
    assert_eq!(clean_verdict, XdpVerdict::Pass);

    let mut attack_packet = vec![0u8; 24];
    attack_packet[12..16].copy_from_slice(&[198, 51, 100, 42]); // Source: Blocked IP
    let attack_verdict = xdp_firewall_hook(&attack_packet, &blocked_ips);
    println!("Ingress Packet from 198.51.100.42 ──► XDP Verdict: {:?}", attack_verdict);
    assert_eq!(attack_verdict, XdpVerdict::Drop);

    // 3. Simulate Kernel Tracepoint Event Stream
    let event = KernelSyscallEvent::new(1042, 1000, 59, "cargo", 0);
    println!("\nCaptured Tracepoint Event from Kernel RingBuffer:");
    println!("  PID:     {}", event.pid);
    println!("  Process: {}", event.process_name());
    println!("  Syscall: {} (sys_execve)", event.syscall_id);
    println!("  Time:    {} ns", event.timestamp_ns);
}
```

## Common Pitfalls & Server Mistakes

### 1. In-Kernel Verifier Rejections
- **Cause**: Using unbounded `while` loops or indexing arrays without explicit bounds checks.
- **Fix**: Always use constant-bounded iterators and explicit slice bounds (`if idx < slice.len()`).

### 2. Exceeding 512-Byte eBPF Stack Limits
- **Cause**: Allocating large structs or local arrays on the eBPF stack.
- **Fix**: Store large data structures in **eBPF Per-CPU Array Maps** instead of the local stack.

## Complete Solutions to Exercises

### Solution 1: Port-Based XDP Drop Filter
```rust
pub fn xdp_block_port(packet: &[u8], blocked_port: u16) -> XdpVerdict {
    if packet.len() < 24 {
        return XdpVerdict::Drop;
    }

    let dest_port = u16::from_be_bytes([packet[22], packet[23]]);
    if dest_port == 20 || dest_port == blocked_port {
        XdpVerdict::Drop
    } else {
        XdpVerdict::Pass
    }
}

#[test]
fn test_port_xdp() {
    let mut packet = vec![0u8; 30];
    packet[22] = 0;
    packet[23] = 22; // Port 22 (SSH)
    assert_eq!(xdp_block_port(&packet, 22), XdpVerdict::Drop);

    packet[23] = 80; // Port 80 (HTTP)
    assert_eq!(xdp_block_port(&packet, 22), XdpVerdict::Pass);
}
```

### Solution 2: eBPF Event Frequency Counter
```rust
use std::collections::HashMap;

pub struct SyscallCounter {
    counts: HashMap<u32, u64>,
}

impl SyscallCounter {
    pub fn new() -> Self {
        Self { counts: HashMap::new() }
    }

    pub fn record_syscall(&mut self, syscall_id: u32) {
        *self.counts.entry(syscall_id).or_insert(0) += 1;
    }

    pub fn get_count(&self, syscall_id: u32) -> u64 {
        *self.counts.get(&syscall_id).unwrap_or(&0)
    }
}

#[test]
fn test_syscall_counter() {
    let mut counter = SyscallCounter::new();
    counter.record_syscall(0); // sys_read
    counter.record_syscall(0); // sys_read
    counter.record_syscall(1); // sys_write
    assert_eq!(counter.get_count(0), 2);
    assert_eq!(counter.get_count(1), 1);
    assert_eq!(counter.get_count(59), 0);
}
```
