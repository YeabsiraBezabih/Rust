## Concept

Standard backend applications interact with the network via high-level TCP/UDP sockets (`AF_INET`). However, building network diagnostic tools, software-defined routers, packet sniffers, or high-performance proxies requires diving into the **Linux Kernel Network Subsystem**.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    Linux Ingress Network Path & Raw Sockets                  │
├──────────────────────────────────────────────────────────────────────────────┤
│  NIC Hardware ──► DMA to Ring Buffer ──► Hardware Interrupt ──► NAPI Polling │
│                                                                      │       │
│  ┌───────────────────────────────────────────────────────────────────┴────┐  │
│  │ Linux Kernel Network Subsystem (`NET_RX_SOFTIRQ`)                      │  │
│  │   • Allocates `struct sk_buff` (Socket Buffer)                         │  │
│  │   • Raw Sockets (`AF_PACKET` / `SOCK_RAW`): Ingests raw Ethernet frames│  │
│  │   • Netfilter / Firewall (`iptables` / `nftables` / eBPF XDP)          │  │
│  │   • IP Layer (Defragmentation, Routing, Checksums)                     │  │
│  │   • TCP Layer (Handshake, Sequence tracking, Flow Control)             │  │
│  └───────────────────────────────────┬────────────────────────────────────┘  │
│                                      │ Passes payload to                     │
│                                      ▼                                       │
│  User Space Application: `TcpStream::read()` or `sendfile()` / `splice()`    │
└──────────────────────────────────────────────────────────────────────────────┘
```

---

### 1. Raw Sockets (`AF_PACKET` & `SOCK_RAW`)

Raw sockets allow your Rust application to bypass the Linux kernel's TCP/IP stack entirely:
- **`AF_PACKET` + `SOCK_RAW`**: Captures and injects raw **Layer 2 (Ethernet)** frames directly to/from network interface cards (NICs). Used by packet sniffers (like Wireshark / `tcpdump`) and custom ARP/DHCP tools.
- **`AF_INET` + `SOCK_RAW`**: Captures and crafts **Layer 3 (IPv4)** packets directly (e.g. creating custom ICMP Ping or raw SYN port scanners).

---

### 2. Netlink Sockets (`rtnetlink`): Kernel Network Management

How do tools like `ip addr add` or `ip route` configure the Linux kernel? They do not use standard file I/O; they communicate with the kernel over **Netlink Sockets (`AF_NETLINK`)**:
- A bidirectional IPC protocol between user-space and kernel subsystems.
- `NETLINK_ROUTE` (`rtnetlink`): Programmatically add/remove IP addresses, bring interfaces up/down, configure routing tables, and modify firewall rules from Rust.

---

### 3. Zero-Copy I/O: `sendfile`, `splice`, & `MSG_ZEROCOPY`

In standard HTTP file servers, serving a static video or file requires:
$$\text{Disk} \xrightarrow{\text{DMA}} \text{Page Cache} \xrightarrow{\text{Copy 1}} \text{User RAM Buffer} \xrightarrow{\text{Copy 2}} \text{Socket Buffer} \xrightarrow{\text{DMA}} \text{NIC}$$

With Linux **Zero-Copy Syscalls**:
- **`sendfile(out_fd, in_fd, offset, count)`**: Copies data directly from the Linux Page Cache to the Network Card DMA ring in kernel space with **ZERO user-space copies**!
- **`splice(fd_in, off_in, fd_out, off_out, len, flags)`**: Transfers data between arbitrary file descriptors using in-kernel pipe buffers without touching user memory.
- **`MSG_ZEROCOPY`**: Socket flag allowing user-space buffers to be pinned and sent directly over the NIC via DMA without copying into kernel memory.

---

## Why It Matters in Systems & Backend Engineering

1. **High-Throughput Static Asset Delivery**: Web servers (Nginx, Axum static file middleware) leverage `sendfile` to stream multi-gigabyte media assets with near-zero CPU usage.
2. **Network Observability & Security Tools**: Building intrusion detection systems (IDS) or custom load balancers requires capturing raw packets via `AF_PACKET`.
3. **Container Network Interface (CNI) Plugins**: Kubernetes CNI plugins (like Calico or Flannel) use `rtnetlink` to dynamically plumb virtual network interfaces into container namespaces.

## Complete, Compilable Code Example

The following Rust program provides a **Raw Ethernet & IPv4 Packet Serializer & Checksum Engine**:

```rust
/// Represents an Ethernet II Frame Header (14 Bytes)
#[repr(C, packed)]
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct EthernetHeader {
    pub dest_mac: [u8; 6],
    pub src_mac: [u8; 6],
    pub ether_type: u16, // 0x0800 for IPv4, 0x0806 for ARP
}

/// Represents an IPv4 Header (20 Bytes Minimum)
#[repr(C, packed)]
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Ipv4Header {
    pub version_ihl: u8,       // Version (4 bits) + Internet Header Length (4 bits)
    pub type_of_service: u8,
    pub total_length: u16,
    pub identification: u16,
    pub flags_fragment_offset: u16,
    pub time_to_live: u8,
    pub protocol: u8,          // 6 = TCP, 17 = UDP, 1 = ICMP
    pub header_checksum: u16,
    pub src_ip: [u8; 4],
    pub dest_ip: [u8; 4],
}

impl Ipv4Header {
    pub fn new(src: [u8; 4], dest: [u8; 4], protocol: u8, payload_len: u16) -> Self {
        let mut header = Self {
            version_ihl: (4 << 4) | 5, // IPv4, 5 x 32-bit words = 20 bytes
            type_of_service: 0,
            total_length: (20 + payload_len).to_be(),
            identification: 0x1234.to_be(),
            flags_fragment_offset: 0x4000.to_be(), // Don't Fragment flag set
            time_to_live: 64,
            protocol,
            header_checksum: 0,
            src_ip: src,
            dest_ip: dest,
        };

        // Compute 16-bit One's Complement Internet Checksum
        header.header_checksum = Self::compute_checksum(&header);
        header
    }

    fn compute_checksum(header: &Ipv4Header) -> u16 {
        let bytes = unsafe {
            std::slice::from_raw_parts(header as *const _ as *const u16, 10)
        };
        let mut sum: u32 = 0;
        for &word in bytes {
            sum += u16::from_be(word) as u32;
        }
        while (sum >> 16) > 0 {
            sum = (sum & 0xffff) + (sum >> 16);
        }
        (!sum as u16).to_be()
    }
}

fn main() {
    println!("=== Linux Raw Socket Packet Serialization & Checksum Engine ===\n");

    let eth_hdr = EthernetHeader {
        dest_mac: [0x52, 0x54, 0x00, 0x12, 0x34, 0x56],
        src_mac:  [0x02, 0x42, 0xac, 0x11, 0x00, 0x02],
        ether_type: 0x0800u16.to_be(), // IPv4
    };

    let ip_hdr = Ipv4Header::new([192, 168, 1, 50], [8, 8, 8, 8], 1, 32); // ICMP Ping

    println!("Constructed Layer 2/3 Packet Wire Headers:");
    println!("  Dest MAC: {:02x}:{:02x}:{:02x}:{:02x}:{:02x}:{:02x}", 
        eth_hdr.dest_mac[0], eth_hdr.dest_mac[1], eth_hdr.dest_mac[2], 
        eth_hdr.dest_mac[3], eth_hdr.dest_mac[4], eth_hdr.dest_mac[5]);
    println!("  Source IP:      {}.{}.{}.{}", ip_hdr.src_ip[0], ip_hdr.src_ip[1], ip_hdr.src_ip[2], ip_hdr.src_ip[3]);
    println!("  Destination IP: {}.{}.{}.{}", ip_hdr.dest_ip[0], ip_hdr.dest_ip[1], ip_hdr.dest_ip[2], ip_hdr.dest_ip[3]);
    println!("  IPv4 Checksum:  0x{:04x}", u16::from_be(ip_hdr.header_checksum));
    assert_ne!(ip_hdr.header_checksum, 0);
}
```

## Common Pitfalls & Server Mistakes

### 1. `Operation not permitted` (`EPERM`) on Raw Sockets
- **Cause**: Creating `AF_PACKET` or `SOCK_RAW` sockets without root privileges or the `CAP_NET_RAW` Linux capability.
- **Fix**: Grant the binary `CAP_NET_RAW` via `sudo setcap cap_net_raw+ep ./my_binary` instead of running the whole program as root.

### 2. Network Interface MTU Overflow
- **Cause**: Crafting raw IP packets larger than the network interface Maximum Transmission Unit (typically 1500 bytes) without enabling IP fragmentation.
- **Fix**: Check interface MTU via `rtnetlink` before constructing raw packet buffers.

## Complete Solutions to Exercises

### Solution 1: MAC Address String Parser
```rust
pub fn parse_mac_address(s: &str) -> Result<[u8; 6], &'static str> {
    let parts: Vec<&str> = s.split(':').collect();
    if parts.len() != 6 {
        return Err("Invalid MAC format");
    }

    let mut mac = [0u8; 6];
    for (i, part) in parts.iter().enumerate() {
        mac[i] = u8::from_str_radix(part, 16).map_err(|_| "Invalid hex byte")?;
    }
    Ok(mac)
}

#[test]
fn test_mac_parser() {
    assert_eq!(
        parse_mac_address("00:1A:2B:3C:4D:5E").unwrap(),
        [0x00, 0x1A, 0x2B, 0x3C, 0x4D, 0x5E]
    );
}
```

### Solution 2: IP Header Protocol Identifier
```rust
pub fn decode_ip_protocol(proto: u8) -> &'static str {
    match proto {
        1 => "ICMP",
        6 => "TCP",
        17 => "UDP",
        _ => "UNKNOWN",
    }
}

#[test]
fn test_protocol_decoder() {
    assert_eq!(decode_ip_protocol(6), "TCP");
    assert_eq!(decode_ip_protocol(17), "UDP");
    assert_eq!(decode_ip_protocol(1), "ICMP");
}
```
