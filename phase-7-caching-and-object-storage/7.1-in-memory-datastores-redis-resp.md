## Concept

Relational databases persist data to disk in 8KB slotted pages. In contrast, **In-Memory Data Stores** (like Redis, Dragonfly, KeyDB) keep their entire active working set in RAM. RAM access latency is $\sim 50 - 100\text{ nanoseconds}$, compared to $\sim 50 - 150\text{ microseconds}$ for NVMe SSDs ($1,000\times$ faster).

To communicate at extreme speeds, Redis uses **RESP (REdis Serialization Protocol)**—a human-readable, binary-safe, CRLF-delimited (`\r\n`) wire format.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        RESP 2 / RESP 3 Framing                         │
├────────────────────────────────────────────────────────────────────────┤
│ Type Tag (1st Byte) │ Meaning             │ Wire Format Example        │
├─────────────────────┼─────────────────────┼────────────────────────────┤
│ `+`                 │ Simple String       │ `+OK\r\n`                  │
│ `-`                 │ Error               │ `-ERR unknown command\r\n` │
│ `:`                 │ Integer             │ `:1000\r\n`                │
│ `$`                 │ Bulk String         │ `$5\r\nhello\r\n`          │
│ `*`                 │ Array               │ `*2\r\n$3\r\nGET\r\n$4\r\n`│
│ `_`                 │ Null (RESP3)        │ `_\r\n`                    │
│ `#`                 │ Boolean (RESP3)     │ `#t\r\n`                   │
└───────────────────────────────────────────┴────────────────────────────┘
```

---

### 1. The RESP Protocol Anatomy

#### Array of Bulk Strings:
Every Redis command sent by a client (e.g. `SET user:101 "Alice"`) is encoded as a RESP **Array of Bulk Strings**:

```text
*3\r\n       <--- Array of 3 elements
$3\r\n       <--- Element 1: Bulk string of length 3
SET\r\n      <--- Element 1 data
$8\r\n       <--- Element 2: Bulk string of length 8
user:101\r\n <--- Element 2 data
$5\r\n       <--- Element 3: Bulk string of length 5
Alice\r\n    <--- Element 3 data
```

#### Null Bulk String:
When a requested key does not exist (`GET non_existent_key`), Redis returns a Null Bulk String:
```text
$-1\r\n
```

---

### 2. Redis vs Dragonfly Architecture

| Feature | Redis (Classic) | Dragonfly (Next-Gen) |
| :--- | :--- | :--- |
| **Concurrency Model** | Single-threaded event loop (`epoll`) | Multi-threaded shared-nothing architecture (fiber per thread) |
| **Max CPU Utilization**| 1 Core per instance | All available CPU cores |
| **Memory Efficiency** | `dict` + `robj` pointers (~40B overhead per key) | Dense compact hashtable with Dashtable bucket layout |
| **Throughput (1 Server)**| $\approx 100,000\text{ ops/sec}$ | $\approx 4,000,000\text{ ops/sec}$ |

---

## Why It Matters in Systems Programming

1. **Sub-Millisecond Read/Write Latency**: Caching database query results, user sessions, or hot counters in Redis reduces API response times from $45\text{ms}$ to $0.4\text{ms}$.
2. **Writing High-Performance Custom Parsers**: Zero-copy RESP parsing using `&[u8]` avoids heap allocations for every incoming command frame.
3. **Atomic Primitives**: Redis commands (`INCR`, `SETNX`, `HSET`, `LPUSH`) execute atomically, making Redis ideal for distributed locks and rate limiters.

## Complete, Compilable Code Example

Below is a complete, self-contained **RESP Protocol Parser and In-Memory Server Engine** in pure Rust:

```rust
use std::collections::HashMap;

// ============================================================================
// 1. RESP Value Representation
// ============================================================================

#[derive(Debug, PartialEq, Eq, Clone)]
pub enum RespValue {
    SimpleString(String),
    Error(String),
    Integer(i64),
    BulkString(Option<Vec<u8>>), // None represents $-1\r\n (Null Bulk String)
    Array(Option<Vec<RespValue>>),
}

// ============================================================================
// 2. Zero-Copy RESP Parser
// ============================================================================

pub struct RespParser;

impl RespParser {
    /// Encodes a RespValue into its raw wire format
    pub fn encode(val: &RespValue) -> Vec<u8> {
        let mut buf = Vec::new();
        match val {
            RespValue::SimpleString(s) => {
                buf.push(b'+');
                buf.extend_from_slice(s.as_bytes());
                buf.extend_from_slice(b"\r\n");
            }
            RespValue::Error(err) => {
                buf.push(b'-');
                buf.extend_from_slice(err.as_bytes());
                buf.extend_from_slice(b"\r\n");
            }
            RespValue::Integer(i) => {
                buf.push(b':');
                buf.extend_from_slice(i.to_string().as_bytes());
                buf.extend_from_slice(b"\r\n");
            }
            RespValue::BulkString(None) => {
                buf.extend_from_slice(b"$-1\r\n");
            }
            RespValue::BulkString(Some(data)) => {
                buf.push(b'$');
                buf.extend_from_slice(data.len().to_string().as_bytes());
                buf.extend_from_slice(b"\r\n");
                buf.extend_from_slice(data);
                buf.extend_from_slice(b"\r\n");
            }
            RespValue::Array(None) => {
                buf.extend_from_slice(b"*-1\r\n");
            }
            RespValue::Array(Some(elements)) => {
                buf.push(b'*');
                buf.extend_from_slice(elements.len().to_string().as_bytes());
                buf.extend_from_slice(b"\r\n");
                for elem in elements {
                    buf.extend_from_slice(&Self::encode(elem));
                }
            }
        }
        buf
    }

    /// Parses a single RESP frame from a byte buffer
    pub fn decode(input: &[u8]) -> Result<(RespValue, usize), &'static str> {
        if input.is_empty() {
            return Err("Empty buffer");
        }

        let prefix = input[0];
        let rest = &input[1..];

        // Find CRLF \r\n
        let crlf_pos = rest
            .windows(2)
            .position(|w| w == b"\r\n")
            .ok_or("Incomplete line: missing CRLF")?;

        let line = &rest[..crlf_pos];
        let line_str = std::str::from_utf8(line).map_err(|_| "Invalid UTF-8")?;

        match prefix {
            b'+' => {
                let consumed = 1 + crlf_pos + 2;
                Ok((RespValue::SimpleString(line_str.to_string()), consumed))
            }
            b'-' => {
                let consumed = 1 + crlf_pos + 2;
                Ok((RespValue::Error(line_str.to_string()), consumed))
            }
            b':' => {
                let val: i64 = line_str.parse().map_err(|_| "Invalid integer")?;
                let consumed = 1 + crlf_pos + 2;
                Ok((RespValue::Integer(val), consumed))
            }
            b'$' => {
                let len: i64 = line_str.parse().map_err(|_| "Invalid bulk string length")?;
                if len == -1 {
                    return Ok((RespValue::BulkString(None), 1 + crlf_pos + 2));
                }
                let len = len as usize;
                let data_start = 1 + crlf_pos + 2;
                let data_end = data_start + len;

                if input.len() < data_end + 2 {
                    return Err("Incomplete bulk string payload");
                }
                if &input[data_end..data_end + 2] != b"\r\n" {
                    return Err("Malformed bulk string trailing CRLF");
                }

                let payload = input[data_start..data_end].to_vec();
                let consumed = data_end + 2;
                Ok((RespValue::BulkString(Some(payload)), consumed))
            }
            b'*' => {
                let count: i64 = line_str.parse().map_err(|_| "Invalid array count")?;
                if count == -1 {
                    return Ok((RespValue::Array(None), 1 + crlf_pos + 2));
                }

                let count = count as usize;
                let mut cursor = 1 + crlf_pos + 2;
                let mut elements = Vec::with_capacity(count);

                for _ in 0..count {
                    let (elem, consumed) = Self::decode(&input[cursor..])?;
                    elements.push(elem);
                    cursor += consumed;
                }

                Ok((RespValue::Array(Some(elements)), cursor))
            }
            _ => Err("Invalid RESP type tag"),
        }
    }
}

// ============================================================================
// 3. Mini In-Memory Redis KV Engine
// ============================================================================

pub struct MiniRedisStore {
    kv: HashMap<String, Vec<u8>>,
}

impl MiniRedisStore {
    pub fn new() -> Self {
        Self { kv: HashMap::new() }
    }

    pub fn execute_command(&mut self, resp: RespValue) -> RespValue {
        let elements = match resp {
            RespValue::Array(Some(elems)) if !elems.is_empty() => elems,
            _ => return RespValue::Error("ERR unknown command".to_string()),
        };

        // Extract command name
        let cmd = match &elements[0] {
            RespValue::BulkString(Some(bytes)) => String::from_utf8_lossy(bytes).to_uppercase(),
            RespValue::SimpleString(s) => s.to_uppercase(),
            _ => return RespValue::Error("ERR invalid command format".to_string()),
        };

        match cmd.as_str() {
            "PING" => RespValue::SimpleString("PONG".to_string()),
            "SET" => {
                if elements.len() < 3 {
                    return RespValue::Error("ERR wrong number of arguments for 'set'".to_string());
                }
                let key = match &elements[1] {
                    RespValue::BulkString(Some(b)) => String::from_utf8_lossy(b).to_string(),
                    _ => return RespValue::Error("ERR invalid key".to_string()),
                };
                let val = match &elements[2] {
                    RespValue::BulkString(Some(b)) => b.clone(),
                    _ => return RespValue::Error("ERR invalid value".to_string()),
                };

                self.kv.insert(key, val);
                RespValue::SimpleString("OK".to_string())
            }
            "GET" => {
                if elements.len() < 2 {
                    return RespValue::Error("ERR wrong number of arguments for 'get'".to_string());
                }
                let key = match &elements[1] {
                    RespValue::BulkString(Some(b)) => String::from_utf8_lossy(b).to_string(),
                    _ => return RespValue::Error("ERR invalid key".to_string()),
                };

                match self.kv.get(&key) {
                    Some(data) => RespValue::BulkString(Some(data.clone())),
                    None => RespValue::BulkString(None), // $-1\r\n (Null)
                }
            }
            _ => RespValue::Error(format!("ERR unknown command '{}'", cmd)),
        }
    }
}

// ============================================================================
// 4. Execution & Verification
// ============================================================================

fn main() {
    println!("=== 1. Decoding Incoming RESP Command: SET session:99 \"RustRules\" ===");
    let raw_set_command = b"*3\r\n$3\r\nSET\r\n$10\r\nsession:99\r\n$9\r\nRustRules\r\n";
    let (decoded_cmd, consumed) = RespParser::decode(raw_set_command).unwrap();
    println!("Consumed {} bytes: {:?}", consumed, decoded_cmd);

    let mut store = MiniRedisStore::new();
    let response = store.execute_command(decoded_cmd);
    println!("Server Response: {:?}", response);
    let wire_bytes = RespParser::encode(&response);
    println!("Wire Output:     {:?}\n", String::from_utf8_lossy(&wire_bytes));

    println!("=== 2. Decoding GET session:99 ===");
    let raw_get_command = b"*2\r\n$3\r\nGET\r\n$10\r\nsession:99\r\n";
    let (decoded_get, _) = RespParser::decode(raw_get_command).unwrap();
    let response_get = store.execute_command(decoded_get);
    println!("Server Response: {:?}", response_get);
    println!("Wire Output:     {:?}\n", String::from_utf8_lossy(&RespParser::encode(&response_get)));

    println!("=== 3. Decoding GET non_existent_key (Null Bulk String) ===");
    let raw_missing_get = b"*2\r\n$3\r\nGET\r\n$7\r\nunknown\r\n";
    let (decoded_missing, _) = RespParser::decode(raw_missing_get).unwrap();
    let response_missing = store.execute_command(decoded_missing);
    println!("Server Response: {:?}", response_missing);
    println!("Wire Output:     {:?}", String::from_utf8_lossy(&RespParser::encode(&response_missing)));
}
```

## Common Pitfalls & Compiler Errors

### 1. Forgetting CRLF Endings
In RESP, every token, line, and bulk string payload MUST end with `\r\n` (CRLF). Ending with just `\n` causes Redis servers to stall waiting for the missing `\r`.

### 2. Confusing Simple String (`+`) with Bulk String (`$`)
Simple Strings (`+OK\r\n`) cannot contain newlines or binary zero bytes. Binary data, JSON payloads, or strings containing spaces/newlines must always be encoded as **Bulk Strings** (`$length\r\ndata\r\n`).

## Complete Solutions to Exercises

### Solution 1 & 2: INCR and DEL Implementation

```rust
// Inside `execute_command` match arm:
"INCR" => {
    if elements.len() < 2 {
        return RespValue::Error("ERR wrong number of arguments for 'incr'".to_string());
    }
    let key = match &elements[1] {
        RespValue::BulkString(Some(b)) => String::from_utf8_lossy(b).to_string(),
        _ => return RespValue::Error("ERR invalid key".to_string()),
    };

    let current = match self.kv.get(&key) {
        Some(bytes) => {
            let s = String::from_utf8_lossy(bytes);
            match s.parse::<i64>() {
                Ok(n) => n,
                Err(_) => return RespValue::Error("ERR value is not an integer".to_string()),
            }
        }
        None => 0,
    };

    let new_val = current + 1;
    self.kv.insert(key, new_val.to_string().into_bytes());
    RespValue::Integer(new_val)
}
"DEL" => {
    if elements.len() < 2 {
        return RespValue::Error("ERR wrong number of arguments for 'del'".to_string());
    }
    let key = match &elements[1] {
        RespValue::BulkString(Some(b)) => String::from_utf8_lossy(b).to_string(),
        _ => return RespValue::Error("ERR invalid key".to_string()),
    };

    let count = if self.kv.remove(&key).is_some() { 1 } else { 0 };
    RespValue::Integer(count)
}
```
